册别: 九年级上册
单元: 第五单元 步入近代
课序: 14
课题: 文艺复兴运动
课标要求: 知道但丁、达·芬奇、莎士比亚等代表人物及其作品，理解文艺复兴运动的意义。
核心素养:
  - 历史解释
  - 史料实证
  - 审美判断
关键词:
  - 人文主义
  - 但丁
  - 神曲
  - 达·芬奇
  - 莎士比亚
知识点:
  - 兴起：14 世纪意大利，最早出现资本主义萌芽
  - 核心思想：人文主义，以人为中心而不是以神为中心，肯定人的价值和尊严
  - 但丁：创作长诗《神曲》，抨击教会的贪婪腐化，被誉为文艺复兴的先驱
  - 达·芬奇：《蒙娜丽莎》《最后的晚餐》，把艺术与科学结合
  - 莎士比亚：《罗密欧与朱丽叶》《哈姆雷特》，反映人文主义思想
  - 扩展：15—16 世纪从意大利扩展到欧洲其他国家
  - 意义：促进了人们思想的大解放，为欧洲资本主义的产生和发展奠定了思想文化基础
重难点: 人文主义的内涵；文艺复兴的实质与意义
易错点: 文艺复兴不是简单“复兴”古代希腊罗马文化，而是借古典文化之名宣传资产阶级新思想；但丁是“先驱”，不能说文艺复兴始于但丁一个人；莎士比亚是英国人，不是意大利人
教学建议: 并置中世纪圣母像与拉斐尔《西斯廷圣母》，只问一句“画里的人变了什么”，让学生自己说出“从神到人”；人文主义用一句话钉死——“人，值得被认真对待”

## 板书提纲

```
文艺复兴（14 世纪，意大利）
├─ 根源：资本主义萌芽
├─ 核心：人文主义（以人为中心）
├─ 代表
│   ├─ 但丁《神曲》——先驱
│   ├─ 达·芬奇《蒙娜丽莎》
│   └─ 莎士比亚《哈姆雷特》
└─ 意义：思想解放 → 为资本主义奠基
```

## 图像对比

左：中世纪圣母像（僵硬、平面、金色背景，人物瘦削呆板）
右：拉斐尔《西斯廷圣母》（人体饱满、有透视、表情自然、怀抱婴儿如常人母子）

设问：如果只能用一个词概括两幅画的差别，你会用哪个词？
（要点：从“神性”到“人性”；画家开始观察真实的人体与空间。）

## 课堂小结一句话

他们说的是“回到古典”，做的其实是“发现人”。
