册别: 九年级上册
单元: 第五单元 步入近代
课序: 16
课题: 早期殖民掠夺
课标要求: 知道“三角贸易”，理解欧洲殖民掠夺对资本主义发展的作用。
核心素养:
  - 唯物史观
  - 时空观念
  - 家国情怀
关键词:
  - 三角贸易
  - 无敌舰队
  - 资本原始积累
  - 种植园
  - 黑奴
知识点:
  - 最早进行殖民扩张的是葡萄牙和西班牙
  - 英国后来居上：1588 年击败西班牙“无敌舰队”，18 世纪成为最大的殖民国家
  - 三角贸易：出程从欧洲运廉价工业品到非洲；中程把黑奴运到美洲；归程把美洲的金银和原料运回欧洲
  - 殖民掠夺的方式：抢劫金银、垄断贸易、贩卖黑奴、经营种植园
  - 影响：为欧洲资本主义发展提供了资本原始积累，同时给亚非拉人民带来深重灾难
重难点: 三角贸易的路线与实质；殖民掠夺的双重影响
易错点: 三角贸易三段各运什么都容易记反，记法：出程“货去非洲”，中程“人去美洲”，归程“钱回欧洲”；“资本原始积累”与“资本积累”不是一回事，前者靠掠夺，后者靠剥削剩余价值；最早殖民的是葡西，不是英国
教学建议: 画三角航线图，让学生在三段上分别标注“运什么、谁获利、谁受害”，一张图把经济链条与人道代价同时呈现，避免只算经济账

## 板书提纲

```
早期殖民掠夺
├─ 最早：葡萄牙、西班牙
├─ 英国：1588 击败无敌舰队 → 18 世纪最大殖民国家
├─ 三角贸易
│   ├─ 出程：欧洲 → 非洲（工业品）
│   ├─ 中程：非洲 → 美洲（黑奴）
│   └─ 归程：美洲 → 欧洲（金银、原料）
└─ 作用：资本原始积累（血腥）
```

## 课堂小结一句话

欧洲港口城市的每一块砖，都压着大西洋底的一段航程。
