# 人教版初中历史教材知识库索引

把 7—9 年级六册教材的知识点索引，做成一个**可检索、可协作、可留痕**的结构化仓库。

每课一个 Markdown 文件（元数据 + 正文），脚本自动校验、生成检索网页、统计进度报表，GitHub Actions 自动构建并发布到 GitHub Pages —— 教室电脑、手机、办公室都能随时打开。

> 只存教师自己整理的索引框架与教学要点，**不存放教材 PDF 原件与扫描页**。

## 目录结构

```
.
├── index/                     ← 内容在这里，按册分目录，一课一文件
│   ├── 七年级上册/
│   │   └── 第01课-中国早期人类的代表北京人.md
│   └── ...
├── scripts/build.py           ← 校验 + 生成网页 + 生成报表
├── scripts/quiz.py            ← 从易错点、知识点自动出题（辨析、填空、简答）
├── templates/课时模板.md       ← 新增课时就复制它
├── docs/                      ← 自动生成，GitHub Pages 从这里发布
│   ├── index.html
│   └── data.json
├── 专题/                       ← 10 个中考复习专题，按主线串联课时
├── 题库/                       ← 自动生成的分册题库与 A4 打印版
├── 使用手册.html / 使用手册.pdf  ← 一页纸操作说明，可打印放办公桌
├── 报表/覆盖度报表.md          ← 自动生成，给教研组和教导处看的进度台账
└── .github/
    ├── workflows/build.yml    ← 自动校验、构建、发布
    ├── ISSUE_TEMPLATE/        ← 提"补录"和"纠错"的表单
    └── pull_request_template.md
```

## 新增一课怎么操作

1. 复制 `templates/课时模板.md` 到对应册别目录，文件名用 `第08课-课题名称.md`
2. 填写开头的元数据（`---` 之间的部分），12 个字段别漏
3. 在本地跑一次校验：

```bash
pip install -r requirements.txt
python3 scripts/build.py --check
```

4. 校验通过后生成网页：

```bash
python3 scripts/build.py
```

5. 双击 `docs/index.html` 就能在浏览器里看效果

## 出一份练习（按册、按单元）

```bash
python3 scripts/quiz.py --book 八年级上册                      # 整册：辨析 + 填空
python3 scripts/quiz.py --book 八年级上册 --unit 第三单元       # 只要一个单元
python3 scripts/quiz.py --book 九年级下册 --type 辨析,填空,简答  # 加简答题
```

产物在 `题库/`：`八年级上册.md` 是题库（含答案与出处），`八年级上册-打印版.html` 用浏览器打开后直接打印，答案在最后一页。

题干预设取自课时原文，不自动造句——辨析题把「易错点」原位改成两个选项（如“洋务运动是（A. 资产阶级改革 / B. 地主阶级的自救运动）”），所以不会出现机器写的病句。**自动出题只作初稿**，印前扫一眼答案里的出处，按班级情况微调。

## 元数据字段说明

| 字段 | 填什么 | 举例 |
| --- | --- | --- |
| `册别` | 必须是六册标准名之一 | 八年级上册 |
| `单元` | 单元序号 + 单元名 | 第一单元 中国开始沦为半殖民地半封建社会 |
| `课序` | 纯数字，用于排序和查重 | 1 |
| `课题` | 课时标题 | 鸦片战争 |
| `课标要求` | 抄课标原文，不要自己改写 | 讲述林则徐虎门销烟的故事…… |
| `核心素养` | 列表，从五大素养里选 | 唯物史观、史料实证 |
| `关键词` | 列表，3—6 个，供检索 | 虎门销烟、南京条约 |
| `知识点` | 列表，一条一个知识点 | 割香港岛给英国 |
| `重难点` | 一句话说清 | 鸦片战争爆发的根本原因 |
| `易错点` | **这一栏最值钱**，写学生真会错的 | 根本原因答成"虎门销烟" |
| `教学建议` | 具体的课堂动作，不要写"加强引导" | 用中英贸易白银流向图切入 |
| `状态` | 已定稿 / 待复核 / 草稿 | 已定稿 |

## 为什么要用 Git 管这个

- **改错了能回退**：教材修订、课标调整，改动都有记录，随时比对上一版
- **教研组能并行**：各人负责不同册，分支互不干扰，合并前互相审
- **进度看得见**：`报表/覆盖度报表.md` 每次构建自动刷新，检查时不用再问"补到哪了"
- **不用装软件**：网页版就能改，手机上也能提交

## 教研组协作流程

1. 在 Issues 里领任务（有"补录课时"和"索引纠错"两个表单）
2. 新建分支：`git checkout -b 补录/八上第5课`
3. 提交并推送，发起 Pull Request
4. 同组教师按 PR 模板里的清单逐项核对，留批注
5. 合并到 `main`，Actions 自动构建并发布
