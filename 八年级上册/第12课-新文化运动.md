课题: 新文化运动
课标要求: 知道陈独秀、胡适等新文化运动的代表人物，了解新文化运动在中国近代思想解放运动中的地位和作用。
核心素养:
  - 历史解释
  - 史料实证
  - 家国情怀
关键词:
  - 陈独秀
  - 新青年
  - 民主与科学
  - 白话文
  - 思想解放
知识点:
  - 背景：辛亥革命后民主共和观念传播，但北洋军阀掀起尊孔复古逆流
  - 兴起标志：1915 年陈独秀在上海创办《青年杂志》，第二年改名《新青年》
  - 代表人物：陈独秀、胡适、李大钊、鲁迅
  - 主要阵地：《新青年》和北京大学
  - 内容之一：抨击旧道德和旧文化，鲁迅《狂人日记》以白话文揭露封建礼教
  - 内容之二：提倡民主与科学，即“德先生”和“赛先生”
  - 内容之三：文学革命，胡适《文学改良刍议》主张白话文，陈独秀《文学革命论》
  - 影响：动摇了封建道德礼教的统治地位，促进思想解放，为五四运动作了思想准备
  - 局限：对东西方文化的看法存在绝对肯定或绝对否定的偏向
重难点: 新文化运动的内容与历史影响
易错点: 兴起标志是 1915 年创办《青年杂志》，改名《新青年》是次年的事；民主与科学对应“德先生”“赛先生”，不要与“自强”“求富”混；新文化运动性质是思想解放运动，不是政治运动或革命运动；评价必须辩证，既要讲解放作用，也要讲绝对化偏向
教学建议: 从“制度换了，人心没换”破题——辛亥革命建立了共和，为什么袁世凯还要尊孔？把新文化运动放进这个困境里，学生才理解它为何必须发生；用《狂人日记》白话原文与文言文改写片段对读，让学生直观感受“文学革命”的意义

## 板书提纲

```
新文化运动（1915—）
├─ 背景：共和已立，尊孔复古逆流
├─ 标志：1915 《青年杂志》（次年改《新青年》）
├─ 人物：陈独秀、胡适、李大钊、鲁迅
├─ 阵地：《新青年》+ 北京大学
├─ 内容
│   ├─ 破：旧道德旧文化
│   ├─ 立：民主（德先生）、科学（赛先生）
│   └─ 形式：白话文
└─ 影响：思想解放 → 为五四准备 / 局限：绝对化
```

## 材料研读

“我翻开历史一查……每页都写着‘仁义道德’几个字……仔细看了半夜……满本都写着两个字是‘吃人’！”——鲁迅《狂人日记》

设问：鲁迅批判的是什么？他为什么用白话文来写？
（要点：批判以“仁义道德”为名的封建礼教；白话文让普通读者能读懂，思想启蒙必须先从语言上打破门槛。）

## 课堂小结一句话

他们争的不只是文言与白话，而是中国人该用什么样的头脑来想问题。
