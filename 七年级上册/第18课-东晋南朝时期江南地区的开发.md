课标要求: 了解东晋南朝的更替，知道江南地区开发的原因与表现。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 东晋
  - 南朝
  - 江南开发
  - 北人南迁
  - 建康
知识点:
  - 317 年，司马睿在建康建立东晋；420 年，刘裕建立宋，此后齐、梁、陈相继，史称“南朝”
  - 江南开发的原因：北方战乱，大量人口南迁，带来劳动力、先进生产工具和技术；江南自然条件优越，社会相对安定；统治者重视农业
  - 表现：开垦荒地、兴修水利；水稻育秧移栽、麦稻兼作；手工业（缫丝、织布、制瓷、造纸）发展；建康成为繁华都市
  - 影响：为后来经济重心南移奠定基础
重难点: 江南开发的原因
易错点: 江南开发最主要的原因是北方人口南迁带来劳动力和技术，不是江南本来就很富；“南朝”是宋齐梁陈四朝，都建康（今南京）；东晋建立是 317 年，西晋灭亡是 316 年，紧接；经济重心南移完成是在南宋，不是南朝，此时只是“奠定基础”
教学建议: 用“为什么人往南走”开场，战乱推力与安定拉力一并讲，因果关系清晰；开发表现按“农业—手工业—城市”三层梳理，配《宋书》记载“一岁或稔，则数郡忘饥”，让学生感受变化之大；一定要强调这是“奠定基础”，避免学生误记经济重心此时已南移

## 板书提纲

```
东晋南朝与江南开发
├─ 317 司马睿建东晋（建康）
├─ 420 起：宋齐梁陈 → 南朝
├─ 开发原因
│   ├─ 北人南迁：劳动力 + 工具 + 技术
│   ├─ 江南自然条件好，社会安定
│   └─ 统治者重视农业
├─ 表现：垦荒水利、稻麦兼作、手工业、建康繁荣
└─ 影响：为经济重心南移奠定基础
```

## 材料研读

“江南之为国盛矣……地广野丰，民勤本业，一岁或稔，则数郡忘饥。”——《宋书》

设问：这段记载描述的江南，与《史记》里“地广人稀”的江南，差别从何而来？
（要点：人口南迁、技术进步、长期安定经营。）

## 课堂小结一句话

北方打碎的东西，被南下的人一担一担挑到了江南。
