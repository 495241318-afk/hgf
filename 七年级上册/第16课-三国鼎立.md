知识点:
  - 200 年官渡之战，曹操以少胜多打败袁绍，为统一北方奠定基础
  - 208 年赤壁之战，孙刘联军以火攻大败曹军，为三国鼎立局面形成奠定基础
  - 220 年曹丕称帝，国号魏，定都洛阳；221 年刘备称帝，国号汉（蜀），定都成都；229 年孙权称帝，国号吴，定都建业
  - 三国鼎立局面形成
  - 经济：曹魏重视农业、兴修水利、推行屯田；蜀汉发展经济、改善与西南少数民族关系；孙吴开发江东，造船业发达，230 年派卫温率船队到达夷洲（今台湾）
重难点: 赤壁之战与三国鼎立的关系；三国鼎立的历史作用
易错点: 官渡之战（200）是曹操胜袁绍，赤壁之战（208）是孙刘胜曹操，两次战役胜负方不同；三国鼎立正式形成是 229 年孙权称帝，不是 220 年曹丕称帝；曹操本人没有称帝，称帝的是其子曹丕；卫温到夷洲是孙吴，230 年，说明台湾自古与大陆联系
教学建议: 两场战役用地图对照讲，官渡是“以少胜多”，赤壁也是“以少胜多”，但胜负方不同，让学生自己找出关键变量（粮草、火攻、水土不服）；三国鼎立不要只讲分裂，要讲它在局部统一中恢复经济的作用，为后面西晋统一埋伏笔；卫温到夷洲这一条务必强调，是台湾与大陆交往的重要史实

## 板书提纲

```
三国鼎立（200—229）
├─ 200 官渡之战：曹操胜袁绍 → 统一北方基础
├─ 208 赤壁之战：孙刘胜曹操 → 鼎立基础
├─ 220 曹丕称帝（魏，洛阳）
├─ 221 刘备称帝（蜀，成都）
├─ 229 孙权称帝（吴，建业）→ 鼎立形成
└─ 经济：魏屯田；蜀开发西南；吴开发江东
        230 卫温到夷洲（台湾）
```

## 材料研读

“老骥伏枥，志在千里。”——曹操《龟虽寿》

设问：写这首诗时的曹操，与赤壁之战后的曹操，处境有何不同？
（要点：前者雄心勃勃、统一在望；后者受挫，转而经营北方。）

## 课堂小结一句话

赤壁那把火烧掉了统一的可能，却烧出了三块各自生长的土地。
