课标要求: 了解夏、商、西周三代更替的史实，知道分封制和西周的灭亡。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证
关键词:
  - 夏朝
  - 世袭制
  - 商汤
  - 分封制
  - 武王伐纣
知识点:
  - 约公元前 2070 年，禹建立夏朝，这是中国历史上第一个王朝
  - 禹死后，其子启继位，世袭制代替禅让制，“公天下”变为“家天下”
  - 约公元前 1600 年，汤灭夏建商；商朝后期盘庚迁都到殷
  - 公元前 1046 年，周武王在牧野之战中大败商军，建立西周，定都镐京
  - 分封制：周王把土地和人民分给宗亲、功臣，封为诸侯；诸侯要服从周王命令、向周王进献贡物、随从作战
  - 分封制的作用：稳定周初政治形势，扩大统治范围；后期诸侯势力坐大，导致分裂
  - 公元前 771 年，犬戎攻破镐京，西周灭亡
重难点: 分封制的内容与双重作用
易错点: 夏朝建立是约公元前 2070 年，禹建立；启继位标志世袭制开始，不是禹；牧野之战是周武王打败商纣王，不是商汤灭夏（那是鸣条之战）；西周灭亡是公元前 771 年犬戎攻破镐京，不是被诸侯所灭
教学建议: 用“公天下到家天下”这条线贯穿，学生能抓住制度变化的实质；分封制用金字塔图呈现等级，再追问“诸侯强了会怎样”，自然过渡到春秋战国的动荡；时间上注意公元前与公元的区别，这是初中生最容易混淆的点，可专门练一次年代计算

## 板书提纲

```
夏商周的更替
├─ 夏（约前2070）禹建，启继位 → 世袭制
├─ 商（约前1600）汤灭夏；盘庚迁殷
├─ 西周（前1046）武王伐纣，牧野之战，都镐京
│   └─ 分封制：分土地人民给宗亲功臣
│       义务：服从、纳贡、从征
│       作用：稳政局、扩疆域；后期诸侯坐大
└─ 前771 犬戎破镐京，西周亡
```

## 材料研读

“大道之行也，天下为公……今大道既隐，天下为家。”——《礼记·礼运》

设问：“天下为公”与“天下为家”分别对应哪种制度？
（要点：禅让制与世袭制；本质是公共权力变为家族私有。）

## 课堂小结一句话

从禹到启，一步之差，中国的权力从此开始在一个家族里传递。
