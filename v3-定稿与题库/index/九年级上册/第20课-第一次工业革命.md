  - 开始：18 世纪 60 年代，哈格里夫斯发明珍妮机，棉纺织业率先出现机器生产
  - 核心发明：1785 年瓦特改良的蒸汽机投入使用，人类进入“蒸汽时代”
  - 交通变革：1825 年史蒂芬孙设计的蒸汽机车试车成功，铁路时代到来
  - 生产组织：现代工厂制度确立，生产集中在工厂中进行
  - 影响：生产力极大提高，英国成为“世界工厂”；社会日益分裂为工业资产阶级和工业无产阶级两大对立阶级
重难点: 工业革命为什么首先发生在英国；工业化时代来临的历史意义
易错点: 工业革命开始于棉纺织业（珍妮机），不是冶金业；瓦特是改良蒸汽机，不是发明蒸汽机；开始的标志是珍妮机发明，完成的标志是机器大生产取代手工劳动，不要与“核心标志是蒸汽机广泛应用”混为一谈；首先发生在英国的根本原因是资本主义制度的建立提供了政治保障，不只是资源丰富；工业革命后世界市场基本形成，最终形成要等到第二次工业革命

## 板书提纲

```
第一次工业革命（18 世纪 60 年代，英国）
├─ 前提：制度、资本、劳动力、市场
├─ 开始：珍妮机（棉纺织业，1765）
├─ 核心：瓦特改良蒸汽机（1785）→ 蒸汽时代
├─ 交通：史蒂芬孙 蒸汽机车（1825）→ 铁路时代
├─ 组织：工厂制度 → 生产集中、分工协作
└─ 影响：世界工厂 / 两大阶级 / 世界市场基本形成
```

## 手工工场与工厂的对比

| 比较项 | 手工工场 | 现代工厂 |
| --- | --- | --- |
| 动力 | 人力、畜力、水力，受自然条件限制 | 蒸汽机，可建在原料与市场附近 |
| 工具 | 手工工具，工人凭技艺操作 | 机器生产，工人服从机器节奏 |
| 规模与组织 | 分散或简单协作，规模有限 | 集中生产，细致分工，有严格规章 |
| 工人身份 | 工匠，技艺决定地位 | 出卖劳动力的雇佣工人 |
| 生产效率 | 低，产量受人力限制 | 大幅提高，产品成本下降 |

设问：机器进了厂房，变化最大的是“生产工具”还是“人与人的关系”？
（要点：两者都变，但工厂制度的确立使雇佣关系成为主导，这是生产关系层面的变化。）

## 数据材料

- 1850 年前后，英国煤产量约占世界总产量的三分之二，生铁产量占世界一半以上。
- 1850 年英国铁路里程约 1 万公里，居世界第一；伦敦到各地的通行时间由数天缩短到数小时。
- 1851 年伦敦万国工业博览会上，英国展出蒸汽机车、汽轮机等，被称为“世界工厂”的自我展示。

设问：一组数字为什么能说明“世界工厂”这个称号？
（要点：煤铁是工业的粮食，产量占比说明工业能力；铁路里程说明交通与市场整合能力。）

## 课堂讨论

材料：一名英国纱厂童工回忆，“机器一开，我们就得跟着它转，慢一步就要挨打”。

设问：工业革命带来了“生产力极大提高”，这段材料提醒我们还应当看到什么？
（要点：工人劳动强度大、工时长为常态，妇女与童工被大量使用；评价工业革命要兼顾生产力进步与阶级对立、社会问题两个面。）

## 与下一课的衔接

本课解决“机器如何取代手工”，下接九年级下册第 5 课“第二次工业革命”：
- 第一次：以蒸汽为动力，轻工业为主，英国一枝独秀；
- 第二次：以电力、内燃机为动力，重工业为主，多国同时展开。
一句话过渡：蒸汽把工厂点亮，电力把世界连成一张网。

## 课堂小结一句话

蒸汽机解决的不只是动力问题，它把人和机器一起，重新排进了工厂的秩序里。
