  - 公私合营
  - 赎买政策

知识点:
  - 农业改造：1953 年起，国家引导农民组织起来，参加农业生产合作社，走集体化和共同富裕的道路
  - 手工业改造：引导手工业者组织手工业生产合作社
  - 资本主义工商业改造：从加工订货、统购包销到公私合营，实行赎买政策，实现了和平过渡
  - 赎买政策：国家按合营时资本家的资本付给定息，是社会主义改造的创举
  - 完成时间：1956 年底，三大改造基本完成
  - 实质：生产资料私有制向社会主义公有制转变
  - 意义：标志着社会主义基本制度在我国建立起来，我国进入社会主义初级阶段
重难点: 三大改造的实质；社会主义基本制度确立的意义
易错点: 改造方式是合作社和公私合营，不是人民公社（人民公社化运动始于 1958 年，二者常被混）；对资本主义工商业实行的是赎买政策而非无偿没收，这是中国区别于苏联的做法；三大改造 1956 年底“基本完成”，表述不要写成“彻底完成”
教学建议: 用“农民为什么愿意把地入股”做讨论，把改造讲成利益选择而不是单纯的政策推行；把赎买政策与苏联没收资本家财产对照，让学生看出中国道路的特殊性，这一处最容易出彩

## 板书提纲

```
三大改造（1953—1956）
├─ 农业：农业生产合作社（集体化）
├─ 手工业：手工业生产合作社
├─ 资本主义工商业：公私合营 + 赎买（创举）
├─ 实质：私有制 → 公有制
└─ 意义：社会主义基本制度建立（1956 底基本完成）
```

## 对照：中国与苏联的改造方式

| 比较项 | 苏联 | 中国 |
| --- | --- | --- |
| 对资本家 | 没收，驱逐或镇压 | 公私合营 + 赎买，给定息 |
| 结果 | 对抗激烈 | 和平过渡 |

设问：为什么中国能“和平过渡”？这说明了什么？
（要点：民族资产阶级在民主革命中曾是同盟者；政策照顾了各方利益，减少了阻力。）

## 改造前后所有制结构

| 项目 | 改造前（1952 年） | 改造后（1956 年底） |
| --- | --- | --- |
| 农业、手工业 | 个体私有制为主 | 集体所有制（合作社） |
| 资本主义工商业 | 资本家私有制 | 全行业公私合营，实际为国家管理 |
| 国民经济成分 | 国营、合作社、个体、资本主义多种并存 | 社会主义公有制占绝对优势 |
| 社会性质 | 新民主主义社会 | 进入社会主义初级阶段 |

说明：赎买政策的关键是“定息”——国家按核定的私股股金，每年付给资本家固定股息（一般 5 厘，即年息 5%），原定 7 年，后延长到 1966 年停止。这不是无偿没收，资本家保留了部分经济利益，减少了改造阻力。

设问：对资本家“给钱”而不是“没收”，是让步还是策略？
（要点：既是照顾同盟者利益的让步，也是以较小代价完成所有制变革的策略选择。）

## 课堂小结一句话

1956 年底那道分界线，把中国从“新民主主义”送进了“社会主义”。
