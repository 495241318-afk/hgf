课题: 清朝前期社会经济的发展
课标要求: 了解清朝前期农业、手工业和商业的发展。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证
关键词:
  - 康乾盛世
  - 摊丁入亩
  - 商帮
  - 人口增长
  - 手工业
知识点:
  - 农业：推广高产作物（玉米、甘薯），耕地面积扩大，粮食产量提高
  - 税制：1712 年“滋生人丁，永不加赋”；雍正时推行“摊丁入亩”，把丁税平均摊入田赋
  - 手工业：丝织、棉织、制瓷、采矿等发展，出现规模较大的手工工场
  - 商业：形成晋商、徽商等大商帮；工商业市镇繁荣
  - 人口：乾隆末年突破 3 亿，带来人地矛盾、生态压力
  - 总体：清朝前期经济恢复发展，出现“康乾盛世”，但仍以自给自足的自然经济为主体
重难点: 摊丁入亩的意义；人口增长的双重影响
易错点: 摊丁入亩是雍正时期推行，废除了人头税，不是康熙；“滋生人丁，永不加赋”是康熙晚年（1712）；晋商、徽商是商帮，不是手工业组织；人口增长既带来劳动力也带来人地矛盾，要两面看
教学建议: 税制变化要讲清逻辑——人头税取消后人口统计更真实，隐匿人口减少，这是人口数字猛增的重要原因之一；商帮可用晋商票号的故事引入，学生有兴趣；结尾必须点出“盛世之下的人口压力”，为近代危机埋线

## 板书提纲

```
清朝前期社会经济的发展
├─ 农业：玉米甘薯推广；耕地增加
├─ 税制：1712 永不加赋 → 雍正摊丁入亩（废人头税）
├─ 手工业：手工工场扩大
├─ 商业：晋商、徽商；市镇繁荣
└─ 人口：乾隆末破 3 亿 → 人地矛盾、生态压力
   总体：康乾盛世，仍以自然经济为主体
```

## 材料研读

“盛世滋生人丁，永不加赋。”——康熙五十年诏

设问：这条政策为什么会让后来的人口统计数字猛增？
（要点：不再按人丁征税，隐匿人口失去必要；统计更接近实际。）

盛世把人养多了，也把地种薄了。
