课题: 经济体制改革
课标要求: 了解农村改革和社会主义市场经济体制的建立与完善。
核心素养:
  - 唯物史观
  - 历史解释
  - 家国情怀
关键词:
  - 小岗村
  - 家庭联产承包责任制
  - 国有企业改革
  - 社会主义市场经济
  - 十四大
知识点:
  - 背景：十一届三中全会后，人民公社体制下“大锅饭”挫伤农民积极性，农业生产长期徘徊
  - 农村改革：1978 年安徽凤阳小岗村农民率先实行分田包干到户，随后推广为家庭联产承包责任制
  - 土地性质：土地仍归集体所有，农民获得生产经营自主权，改变的是经营方式而非所有制
  - 城市改革：1984 年起全面展开，重点是国有企业改革，扩大企业自主权，实行政企分开
  - 目标确立：1992 年中共十四大提出建立社会主义市场经济体制的目标
  - 意义：调动了生产者和经营者的积极性，促进了经济发展和人民生活水平提高
重难点: 家庭联产承包责任制的实质；社会主义市场经济体制目标的确立
易错点: 家庭联产承包责任制没有改变土地公有制，说“分田到户把土地分给农民”是错的；提出建立社会主义市场经济体制目标的是 1992 年中共十四大；城市经济体制改革全面展开是 1984 年
教学建议: 用小岗村“十八个红手印”契约原件照片导入，先问“他们为什么要冒这个险”；再做“一口锅吃饭”与“各家各户自己种”的收益对比推演，把“积极性”这个抽象词落到产量上

## 板书提纲

```
经济体制改革
├─ 农村（1978 起）
│   └─ 小岗村 → 家庭联产承包责任制
│       土地集体所有 + 经营自主权
├─ 城市（1984 起）
│   └─ 国企改革：扩权、政企分开
└─ 目标（1992 十四大）
    └─ 社会主义市场经济体制
```

## 材料研读

小岗村契约：“我们分田到户，每户户主签字盖章，如以后能干，每户保证完成每户的全年上交和公粮，不再向国家伸手要钱要粮……”

设问：这份契约里，农民向国家承诺了什么？他们承担了多大风险？
（要点：保证完成上交和公粮、不再要救济；在当时被视为“违反政策”，风险是政治性的。）

## 课堂小结一句话

改革的起点不在会议室，而在十八户农民按下红手印的那张纸上。
