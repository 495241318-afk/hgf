单元: 第六单元 科技文化与社会生活
课序: 19
课题: 社会生活的变迁
课标要求: 了解改革开放以来人们衣食住行用等方面的变化。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证
  - 家国情怀
关键词:
  - 衣食住行
  - 消费结构
  - 交通通信
  - 生活方式
  - 改革开放
知识点:
  - 衣：从单调的蓝灰到款式多样、注重个性
  - 食：从凭票供应、吃饱为主，到品种丰富、讲营养讲健康
  - 住：从拥挤简陋到人均居住面积大幅提高、住房商品化
  - 行：从自行车、公交为主，到私家车普及、高铁与民航快速发展
  - 用：从票证时代到移动支付、网络购物、智能家电普及
  - 变化原因：改革开放推动经济发展，科技进步，思想观念更新
  - 特点：变化巨大但不平衡，城乡、区域之间仍有差距
重难点: 生活变化的原因；变化背后的时代意义
易错点: 票证（粮票、布票）是计划经济时期的产物，20 世纪 90 年代前后逐步取消；变化的主要推动力是经济发展与改革开放，不是单靠科技进步；生活变化存在城乡与区域差异，不能一概而论
教学建议: 用老照片、老物件（粮票、缝纫机、BP 机）与学生今天的生活对照，代入感强；可让学生采访祖辈父辈的衣食住行，做小型口述史，这是最好的史料实证训练；结尾讲不平衡，避免把“变化”讲成“人人如此”，保留真实感

## 板书提纲

```
社会生活的变迁
├─ 衣：单调 → 多样个性
├─ 食：票证、吃饱 → 丰富、健康
├─ 住：拥挤 → 面积扩大、住房商品化
├─ 行：自行车 → 私家车、高铁、民航
├─ 用：票证 → 移动支付、网购、智能家电
├─ 原因：改革开放、经济发展、科技进步、观念更新
└─ 特点：变化巨大，但城乡区域仍有差距
```

## 材料研读

“当年买粮要粮票，现在买菜扫一扫。”——民间口述

设问：一句家常话里，藏着哪些制度与技术的变化？
（要点：从计划配给到市场供应；从现金到移动支付。）
