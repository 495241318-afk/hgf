核心素养:

  - 史料实证
  - 历史解释

  - 尼罗河
  - 金字塔
  - 胡夫金字塔
  - 法老
  - 象形文字
知识点:
  - 地理环境：古埃及位于非洲东北角，尼罗河贯穿南北，定期泛滥形成肥沃河谷
  - 文明兴起：约公元前 3500 年开始出现若干小国，公元前 3100 年左右初步实现统一
  - 最高统治者称法老，集军政大权于一身，被视为神的化身
  - 金字塔：法老的陵墓，是古埃及文明的象征，也体现了古埃及劳动人民的智慧
  - 胡夫金字塔：现存最大的金字塔，约用 230 万块巨石砌成，平均每块重 2.5 吨左右
  - 文化成就：象形文字、太阳历、木乃伊制作技术
重难点: 金字塔与古埃及文明的关系；自然环境对早期文明的影响
易错点: 金字塔是法老的陵墓，不是神庙；古埃及文明发源于尼罗河，两河流域是古巴比伦；说金字塔只体现“奴隶主压迫”不完整，它是王权象征也是劳动智慧的结晶
教学建议: 用“为什么早期文明都长在大河边”做横向比较（尼罗河、两河、印度河、黄河），建立文明与环境的关联；用“230 万块巨石、每块 2.5 吨”做数字冲击，再问“没有现代机械怎么做到”，把惊叹转化为对组织能力与技术的思考

## 板书提纲

```
古代埃及
├─ 环境：尼罗河（"埃及是尼罗河的赠礼"）
├─ 兴起：约前 3500 小国 → 前 3100 初步统一
├─ 统治：法老（神化王权）
├─ 象征：金字塔（胡夫，230 万块巨石）
└─ 文化：象形文字、太阳历、木乃伊
```

## 材料研读

“埃及是尼罗河的赠礼。”——希罗多德

设问：这句话是在夸尼罗河，还是在解释埃及文明为什么会出现？请用本课史实支持你的判断。
（要点：尼罗河定期泛滥带来肥沃淤泥，农业发达，人口聚集，国家与王权随之出现。）

## 课堂小结一句话

一条河养出了一个国家，一个国家垒起了一座山。
