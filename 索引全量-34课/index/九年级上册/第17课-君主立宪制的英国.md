课题: 君主立宪制的英国
课标要求: 知道英国资产阶级革命的基本进程，理解君主立宪制的确立。
核心素养:
  - 时空观念
  - 历史解释
  - 唯物史观
关键词:
  - 光荣革命
  - 权利法案
  - 议会主权
  - 君主立宪
  - 查理一世
知识点:
  - 1640 年议会重新召开，英国资产阶级革命爆发
  - 1649 年查理一世被处死，英国宣布为共和国
  - 克伦威尔掌权后实行独裁统治，革命出现曲折
  - 1660 年斯图亚特王朝复辟
  - 1688 年“光荣革命”，不流血政变，确立议会的主导地位
  - 1689 年《权利法案》限制王权，保障议会权力，君主立宪制逐步形成
重难点: 《权利法案》的内容与君主立宪制的确立
易错点: 《权利法案》的作用是限制王权、确立议会主权，不要说成“建立了君主立宪制”这一个动作完成；光荣革命是不流血的政变，不是战争；1649 年建立的是共和国，克伦威尔后来实行的是护国主独裁，两者不同
教学建议: 用“国王能做什么、不能做什么”两张清单对比革命前后，学生填完就明白“立宪”二字的含义；再问“为什么英国人选择了保留国王”，引出妥协传统

## 板书提纲

```
英国资产阶级革命
├─ 1640 议会召开 → 爆发
├─ 1649 查理一世被处死 → 共和国
├─ 克伦威尔独裁 → 1660 复辟
├─ 1688 光荣革命（不流血）
└─ 1689 《权利法案》
    └─ 限制王权、议会主权 → 君主立宪制
```

## 课堂小结一句话

革命砍掉了一个国王的头，最后又请回了一个国王——但权力的位置已经换了。
