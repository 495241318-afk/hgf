知识点:
  - 农学：北朝贾思勰著《齐民要术》，总结北方农业生产经验，是我国现存最早的一部完整的农书
  - 数学：南朝祖冲之把圆周率精确到小数点后第七位，领先世界近千年；著《缀术》
  - 书法：东晋王羲之，代表作《兰亭集序》，被誉为“书圣”
  - 绘画：东晋顾恺之，代表作《女史箴图》《洛神赋图》
  - 石窟：山西大同云冈石窟、河南洛阳龙门石窟，体现佛教艺术与民族交融
  - 特点：科技文化在分裂中仍有巨大成就，为隋唐文化高峰奠基
重难点: 这一时期科技文化成就的历史地位
易错点: 《齐民要术》是贾思勰（北朝），我国现存最早的完整农书；祖冲之是南朝人，圆周率精确到小数点后第七位；王羲之是东晋，被称为“书圣”，《兰亭集序》被誉为“天下第一行书”；云冈石窟在大同（北魏早期），龙门石窟在洛阳（迁都后）
教学建议: 用“分裂时代为何还有文化高峰”设问，引出民族交融与南北交流的作用，避免学生形成“乱世无文化”的误解；祖冲之的圆周率可让学生对比 3.14 与 3.1415926 的精度差别，直观感受领先程度；石窟艺术配图讲，重点看佛像面容与衣饰的变化，能看出民族交融的痕迹

## 板书提纲

```
魏晋南北朝的科技与文化
├─ 农学：贾思勰《齐民要术》（现存最早完整农书）
├─ 数学：祖冲之，圆周率至小数点后第七位
├─ 书法：王羲之《兰亭集序》→ 书圣
├─ 绘画：顾恺之《女史箴图》《洛神赋图》
└─ 石窟：云冈（大同）、龙门（洛阳）
   特点：分裂中仍有高峰，为隋唐奠基
```

## 材料研读

“顺天时，量地利，则用力少而成功多。”——《齐民要术》

设问：这句话体现了怎样的生产观念？它对今天的农业还有意义吗？
（要点：因地制宜、顺应农时；与现代农业的生态理念相通。）

## 课堂小结一句话

政权分裂了三百年，文化却在交流中长成了一片森林。
