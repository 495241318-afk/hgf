知识点:
  - 三家分晋、田氏代齐后，形成齐、楚、燕、韩、赵、魏、秦七雄并立的局面
  - 战争特点：规模大、时间长、伤亡多，从争霸转向兼并
  - 商鞅变法（公元前 356 年，秦孝公支持）：政治上确立县制，由国君直接派官吏治理；废除贵族世袭特权；改革户籍制度；严明法度。经济上废除井田制，允许土地自由买卖；鼓励耕织，生产粮食布帛多的人可免除徭役；统一度量衡。军事上奖励军功
  - 作用：使秦国国力大为增强，提高军队战斗力，成为最强盛的诸侯国，为统一奠定基础
  - 都江堰：公元前 256 年，秦国蜀郡郡守李冰主持修建，集防洪、灌溉、水运于一体，使成都平原成为“天府之国”
重难点: 商鞅变法的内容与历史作用
易错点: 商鞅变法开始于公元前 356 年，支持者是秦孝公，不是秦始皇；确立县制、废除井田制是最核心的两条，前者加强了中央集权，后者确立了土地私有；都江堰是秦国李冰修的，不是秦朝；商鞅本人被车裂，但变法措施未被废除，说明变法成功而个人失败
教学建议: 商鞅变法按“政治—经济—军事”三块梳理，每条讲清“打击了谁、扶植了谁”，学生才理解变法的实质是利益重组；都江堰可以用工程示意图讲“鱼嘴分水、飞沙堰排沙、宝瓶口引水”，这是古代水利智慧的典范；结尾对比“商鞅死而法存”，引导思考制度与个人的关系

## 板书提纲

```
战国时期的社会变化（前475—前221）
├─ 战国七雄：齐楚燕韩赵魏秦
├─ 商鞅变法（前356，秦孝公）
│   ├─ 政治：县制、废世袭、户籍、法治
│   ├─ 经济：废井田、奖耕织、统一度量衡
│   └─ 军事：奖励军功
│   → 秦国最强，为统一奠基
└─ 都江堰（前256，李冰）→ 成都平原“天府之国”
```

## 材料研读

“治世不一道，便国不法古。”——商鞅

设问：这句话是在为变法找什么依据？它要说服的是谁？
（要点：以实效否定守旧；说服秦孝公与旧贵族。）

## 课堂小结一句话

商鞅被车裂了，他的法令却在秦国活了上百年。
