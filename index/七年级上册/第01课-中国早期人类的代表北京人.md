核心素养:
  - 史料实证
  - 时空观念
  - 唯物史观
关键词:
  - 元谋人
  - 北京人
  - 山顶洞人
  - 化石
  - 周口店
知识点:
  - 元谋人：云南元谋，距今约 170 万年，会制造工具和使用火，是我国境内目前已知最早的古人类之一
  - 北京人：北京西南周口店龙骨山，距今约 70 万—20 万年，使用打制石器，会使用天然火并长时间保存火种，群居生活
  - 北京人的体质特征：保留猿的某些特征，但手脚分工明显，能够直立行走
  - 山顶洞人：距今约 3 万年，掌握磨光和钻孔技术，会人工取火，缝制衣服，有审美观念
  - 发现意义：周口店遗址是世界上出土古人类遗物和化石最丰富的遗址之一
重难点: 北京人的体质特征与生活状况；化石为什么能作为研究人类起源的证据
易错点: 北京人距今约 70 万—20 万年，不是 170 万年（那是元谋人）；北京人使用打制石器，属于旧石器时代，不是新石器时代；北京人已经会使用火，但不会人工取火（人工取火是山顶洞人）；发现地点是北京西南周口店龙骨山，不是北京城区；化石是研究远古人类历史的最主要证据，传说不能作为实证
教学建议: 用北京人头盖骨复原像与现代人头骨对比，让学生自己找差异并推测结论，落实史料实证；设计“考古报告”任务单，给出化石照片让学生判断用途

## 板书提纲

```
史前时期
├─ 元谋人（约170万年，云南）——最早
├─ 北京人（约70万—20万年，周口店）
│   ├─ 体质：直立行走、手脚分工、保留猿的特征
│   ├─ 工具：打制石器（旧石器）
│   └─ 用火：天然火
└─ 山顶洞人（约3万年）——磨光钻孔、人工取火、审美
```

## 材料研读

北京人遗址出土了大量打制石器、成堆的灰烬层，以及被火烧过的石块和兽骨。

设问：灰烬层能说明什么？为什么说这是“用火”而不是“野火”？
（要点：成堆、有固定位置、伴生烧骨——说明是长期、有控制地使用火。）

## 课堂小结一句话

化石是打开史前史的钥匙，北京人是这把钥匙上最清晰的一道齿。
