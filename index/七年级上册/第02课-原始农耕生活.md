课题: 原始农耕生活
课标要求: 了解河姆渡、半坡等原始农耕遗址的史实，知道原始农业的兴起。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证
关键词:
  - 河姆渡
  - 半坡
  - 水稻
  - 粟
  - 磨制石器
知识点:
  - 距今约 7000 年，浙江余姚河姆渡遗址，长江流域，种植水稻，住干栏式建筑，会挖水井，制作黑陶
  - 距今约 6000 年，陕西西安半坡遗址，黄河流域，种植粟，住半地穴式圆形房屋，制作彩陶
  - 共同点：使用磨制石器，从事农业生产，饲养家畜，聚落定居
  - 原始农业兴起的重要标志：农作物种植、家畜饲养、聚落、磨制石器的发展
  - 意义：为古代文明社会的形成奠定了重要基础
重难点: 南稻北粟的差异与自然环境的关系
易错点: 河姆渡在长江流域（浙江），种水稻；半坡在黄河流域（陕西），种粟——南北不能颠倒；河姆渡是干栏式建筑（防潮），半坡是半地穴式（保暖），建筑形式与气候直接相关；北京人用打制石器，河姆渡、半坡用磨制石器
教学建议: 用一张中国地图标出两个遗址，让学生自己说出“一个在南一个在北”，再追问“为什么种的东西不一样”，把地理与农业连起来；建筑形式用剖面图对比，干栏式架空防潮、半地穴式下挖保暖，学生一看就懂；本课是“从采集到种植”的转折点，可作为文明起源的起点课

## 板书提纲

```
原始农耕生活
├─ 河姆渡（约7000年前，浙江，长江流域）
│   ├─ 水稻、干栏式建筑、水井、黑陶
└─ 半坡（约6000年前，陕西，黄河流域）
    ├─ 粟、半地穴式房屋、彩陶
共同点：磨制石器 + 种植 + 饲养 + 定居
标志：农作物、家畜、聚落、磨制石器
```

## 材料研读

半坡遗址出土的粟粒与河姆渡遗址出土的稻谷遗存。

设问：两处遗址相距千里，为什么一个种稻、一个种粟？
（要点：水稻需高温多雨，适合长江流域；粟耐旱，适合黄河流域。）
