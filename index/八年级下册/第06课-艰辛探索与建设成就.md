  - 建设成就
知识点:
  - 1956 年中共八大召开，指出国内主要矛盾已转变为人民对于建立先进工业国的要求同落后农业国现实之间的矛盾，是探索社会主义道路的良好开端
  - 1958 年“大跃进”和人民公社化运动，片面追求高速度、高指标，违背客观经济规律，加上自然灾害，造成严重经济困难
  - 1961 年起实行“调整、巩固、充实、提高”方针，经济逐步恢复
  - 1966—1976 年“文化大革命”，给党、国家和各族人民带来新中国成立后最严重的挫折
  - 建设成就：大庆油田（王进喜）、两弹一星（邓稼先、钱学森）、籼型杂交水稻（袁隆平）、人工合成结晶牛胰岛素
重难点: 探索中的失误与成就并存；失误的原因
易错点: 中共八大是正确的探索开端，不是失误；“大跃进”是 1958 年，特点是高指标、瞎指挥、浮夸风、共产风；人民公社化运动强调“一大二公”，与家庭联产承包责任制方向相反；两弹一星是六七十年代成就，不是文革的成果
教学建议: 讲失误要归因于“缺乏经验 + 急于求成 + 违背规律”，不是简单归咎个人，这符合历史唯物主义；成就部分要讲清“在困难条件下仍取得”，突出自力更生；文革部分按教材基调简明处理，落到“吸取教训、以史为鉴”

## 板书提纲

```
艰辛探索与建设成就（1956—1976）
├─ 1956 中共八大：良好开端
├─ 1958 大跃进 + 人民公社化 → 经济困难
├─ 1961 调整方针 → 恢复
├─ 1966—1976 文化大革命 → 严重挫折
└─ 成就：大庆油田、两弹一星、杂交水稻、牛胰岛素
```

## 材料研读

“鼓足干劲、力争上游、多快好省地建设社会主义。”——1958 年总路线
