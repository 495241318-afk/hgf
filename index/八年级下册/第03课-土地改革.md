知识点:
  - 背景：封建土地制度下，地主占有大量土地，农民受剥削，严重阻碍农村经济和中国社会发展
  - 1950 年，中央人民政府颁布《中华人民共和国土地改革法》，规定废除地主阶级封建剥削的土地所有制，实行农民的土地所有制
  - 到 1952 年底，除部分少数民族地区外，全国大陆基本完成土地改革
  - 结果：约 3 亿无地少地农民分到土地，成为土地的主人
  - 意义：彻底摧毁了在我国延续两千多年的封建土地制度，消灭了地主阶级；农民翻了身，生产积极性提高；巩固了新生政权，为工业化建设准备了条件
重难点: 土地改革的性质与意义
易错点: 土地改革是 1950—1952 年，废除的是封建土地所有制，实行农民土地所有制（土地仍归私有，不是公有）；三大改造（1956）才是把土地变为集体所有，两者不能混；土地改革后土地归农民所有，不是国家所有
教学建议: 用“谁的地、谁的粮”讲清所有制变化，学生才明白“翻身”的实质；土地改革与三大改造容易混，可提前预告区别：土改是“分地”，改造是“合地”；意义部分落到政权巩固与工业化，把前后单元串起来

## 板书提纲

```
土地改革（1950—1952）
├─ 背景：封建土地制度阻碍发展
├─ 1950《土地改革法》
│   └─ 废除地主土地所有制 → 农民土地所有制
├─ 1952 底基本完成（少数民族地区除外）
├─ 结果：3 亿农民分到土地
└─ 意义：摧毁封建土地制度；农民翻身；巩固政权
```

## 材料研读

“废除地主阶级封建剥削的土地所有制，实行农民的土地所有制。”——《中华人民共和国土地改革法》

设问：这句话里“所有制”变了什么？没变的是什么？
（要点：所有权主体由地主变为农民；土地私有性质未变。）
