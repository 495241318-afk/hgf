  - 历史解释
关键词:
  - 巴黎和会
  - 凡尔赛条约
  - 九国公约
  - 华盛顿体系
  - 凡尔赛—华盛顿体系
知识点:
  - 1919 年，巴黎和会召开，签订《凡尔赛条约》：重划德国疆界，阿尔萨斯—洛林归还法国；德国海外殖民地被瓜分；限制德国军备；德国负担巨额赔款
  - 巴黎和会还决定建立国际联盟（国联），实际被英法控制
  - 1921—1922 年，华盛顿会议召开，签订《九国公约》，宣称尊重中国主权、独立与领土完整，实际上使中国回到几个帝国主义国家共同支配的局面
  - 凡尔赛—华盛顿体系：确立了战后帝国主义在欧洲、西亚、非洲和亚太地区的新秩序
  - 中国：巴黎和会将德国在山东的权益转给日本，引发五四运动
  - 评价：体系暂时缓和了矛盾，但埋下新的冲突隐患，不可能长期维持
重难点: 凡尔赛—华盛顿体系的实质与局限
易错点: 《凡尔赛条约》是 1919 年对德和约，《九国公约》是 1921—1922 年华盛顿会议签订；国联由巴黎和会决定建立，但美国未加入；《九国公约》表面尊重中国主权，实质是共同支配中国；五四运动的导火线正是巴黎和会中国外交失败
教学建议: 用“分赃会议”定性巴黎和会，讲清战胜国如何处置战败国与殖民地，学生才理解其不义；《九国公约》必须结合中国处境讲，与五四运动呼应，这是爱国主义教育的落点；体系评价要讲“暂时与必然”——暂时缓和、必然崩溃，为二战埋线

## 板书提纲

```
凡尔赛—华盛顿体系
├─ 1919 巴黎和会 →《凡尔赛条约》
│   ├─ 重划德国疆界、瓜分殖民地、限军、赔款
│   └─ 决定建立国联
├─ 1921—1922 华盛顿会议 →《九国公约》
│   └─ 表面尊重中国主权，实质共同支配
├─ 中国：山东权益转日本 → 五四运动
└─ 实质：帝国主义重新瓜分世界；暂时缓和，隐患深埋
```

## 材料研读

“这不是和平，这是二十年的休战。”——福煦对《凡尔赛条约》的评价

设问：他为什么敢这样预言？
（要点：惩罚性条款激化德国民族情绪；体系未解决根本矛盾。）

## 课堂小结一句话

在凡尔赛镜厅签下的那份和约，只是把下一场战争推迟了二十年。
