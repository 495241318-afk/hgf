易错点: 第一次工业革命以蒸汽为动力，第二次以电力、内燃机为核心；爱迪生发明电灯（实用白炽灯），不是发明电；本茨制造汽车，莱特兄弟试飞飞机；垄断组织出现在第二次工业革命时期
教学建议: 与第一次工业革命做表格对比（动力、发明者、科学与技术关系、领先国家），差异一目了然；讲“科学—技术—生产”三者结合是本课核心，这也是第二次革命更快更广的原因；垄断的影响要两面说，生产集中提高效率，也带来对外扩张

## 板书提纲

```
第二次工业革命（19 世纪 70 年代—20 世纪初）
├─ 特点：科学 + 技术 + 生产紧密结合；多国并行
├─ 电力：发电机、电动机 →“电气时代”
├─ 内燃机：汽车（本茨）、飞机（莱特兄弟）；石油
├─ 化工：染料、塑料、人造纤维
├─ 通信：电话、无线电报
└─ 影响：生产力跃升；垄断组织；世界市场形成
```

## 材料研读

“科学是一种在历史上起推动作用的、革命的力量。”——恩格斯

设问：用第二次工业革命的事实，说明这句话。
（要点：电磁学理论 → 发电机 → 电力工业，理论直接转化为生产力。）

## 课堂小结一句话

第一次工业革命靠工匠的经验，第二次靠实验室的公式。
