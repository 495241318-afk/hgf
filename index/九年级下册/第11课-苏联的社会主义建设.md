课标要求: 知道新经济政策、苏联的成立和苏联模式。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 新经济政策
  - 苏联成立
  - 五年计划
  - 农业集体化
  - 苏联模式
知识点:
  - 1921 年，列宁实行新经济政策：以征收粮食税代替余粮收集制；允许使用雇佣劳动力和出租土地；允许私人经营中小企业；实行按劳取酬的工资制
  - 新经济政策从国情出发，调动了生产者的积极性，促进国民经济恢复
  - 1922 年底，苏维埃社会主义共和国联盟（苏联）成立
  - 1928 年起，苏联实施两个五年计划，重点发展重工业，到 1937 年工业总产值跃居欧洲第一、世界第二
  - 20 世纪 30 年代推行农业集体化，建立集体农庄
  - 1936 年新宪法宣布苏联是“工农社会主义国家”，标志苏联模式（斯大林模式）形成
  - 苏联模式特点：高度集中的计划经济体制和高度集权的政治体制
  - 评价：短期内实现工业化，为反法西斯战争胜利奠定物质基础；但排斥市场、片面发展重工业、牺牲农业和农民利益，长期看弊端严重
重难点: 新经济政策的调整；苏联模式的双重影响
易错点: 新经济政策是列宁 1921 年实行，不是斯大林；苏联成立于 1922 年底，不是 1917；五年计划重点发展重工业，不是轻工业；苏联模式形成标志是 1936 年新宪法
教学建议: 用“战时共产主义为什么行不通”引出新经济政策的必要性，学生理解“退一步”的智慧；五年计划成就用数据讲，同时要讲农民付出的代价，避免片面赞颂；苏联模式评价要辩证，短期功绩与长期弊端并存，这是本课最重要的思维训练

## 板书提纲

```
苏联的社会主义建设
├─ 1921 新经济政策（列宁）
│   ├─ 粮食税代余粮收集制
│   ├─ 允许私人工商业、雇佣、出租
│   └─ 按劳取酬 → 经济恢复
├─ 1922 底 苏联成立
├─ 1928 起 两个五年计划（重工业优先）
├─ 30 年代 农业集体化
└─ 1936 新宪法 → 苏联模式形成
   特点：高度集中计划经济 + 高度集权政治
   评价：短期工业化；长期弊端
```

## 材料研读

“我们原打算直接用无产阶级国家的法令，在一个小农国家里按共产主义原则来调整国家的产品生产和分配。现实生活说明我们犯了错误。”——列宁

设问：列宁承认了什么错误？他如何纠正？
（要点：急于过渡到共产主义；改行新经济政策，允许市场因素。）

## 课堂小结一句话

他用一次退却救活了经济，可惜后来的人只记住了向前冲。
