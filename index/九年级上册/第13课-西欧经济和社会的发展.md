册别: 九年级上册
单元: 第五单元 步入近代
课序: 13
课题: 西欧经济和社会的发展
课标要求: 了解西欧租地农场和手工工场的出现，理解欧洲资本主义的萌芽。
核心素养:
  - 唯物史观
  - 历史解释
  - 史料实证
关键词:
  - 租地农场
  - 手工工场
  - 雇佣关系
  - 市民阶层
  - 资本主义萌芽
知识点:
  - 11 世纪后开展垦殖运动，耕地面积扩大，农业生产效率提高
  - 租地农场出现：富裕农民租种土地，雇用少地或无地农民劳动，形成雇佣关系
  - 手工业发展：手工业者脱离农业和领主控制，逐渐形成集中生产的手工工场
  - 雇佣关系的出现，标志着西欧资本主义生产的萌芽
  - 社会结构变化：富裕农民、骑士成为农村中坚力量；市民阶层分化出早期的资产阶级
重难点: 租地农场与手工工场中雇佣关系的实质
易错点: 判断“资本主义萌芽”的关键是雇佣关系，不是规模大小；手工工场不等于工厂（工厂是工业革命后的生产组织）；租地农场主经营的是租来的土地，不是自己的土地
教学建议: 用“谁给谁发工钱”这一问切入，让学生在两段材料里找出雇佣关系的证据，把“萌芽”这个抽象说法落到具体的人与钱上

## 板书提纲

```
西欧经济与社会发展
├─ 11 世纪后 垦殖运动
├─ 农村：租地农场 → 雇用农民 → 雇佣关系
├─ 城市：手工工场 → 集中生产
├─ 关键：雇佣关系 = 资本主义萌芽
└─ 社会：富裕农民、骑士崛起；市民分化出早期资产阶级
```

## 课堂小结一句话

当土地和劳动都变成可以买卖的东西，一个新的时代就开始算了。
