册别: 九年级上册
单元: 第一单元 古代亚非文明
课序: 3
课题: 古代印度
课标要求: 知道古印度的种姓制度，了解佛教的产生。
核心素养:
  - 时空观念
  - 历史解释
  - 唯物史观
关键词:
  - 种姓制度
  - 婆罗门
  - 刹帝利
  - 佛教
  - 释迦牟尼
知识点:
  - 地理环境：印度河流域，早期文明遗址哈拉帕、摩亨佐·达罗
  - 种姓制度：雅利安人进入后逐步形成，按等级分为婆罗门（祭司）、刹帝利（军事贵族与官吏）、吠舍（平民）、首陀罗（被征服者），另有“不可接触者”贱民
  - 制度特点：等级森严、世代相袭、贵贱分明，各等级之间禁止通婚
  - 佛教产生：公元前 6 世纪，乔达摩·悉达多（释迦牟尼）创立，反对种姓制度，主张“众生平等”
  - 佛教外传：公元前 3 世纪阿育王统治时期开始向外传播
  - 文化成就：发明“阿拉伯数字”（后经阿拉伯人传播到欧洲）
重难点: 种姓制度的内容与实质；佛教产生的背景
易错点: 四个等级顺序极易写乱，记法：婆罗门（嘴）—刹帝利（臂）—吠舍（腿）—首陀罗（脚）；佛教反对的是婆罗门的特权地位，不是要彻底废除种姓制度；阿拉伯数字起源于印度，阿拉伯人只是传播者
教学建议: 用“一个首陀罗能否通过努力改变身份”提问，让学生从制度规定中找出“不能”的依据，理解制度的刚性；再问“佛教为什么会在这样的社会里受欢迎”

## 板书提纲

```
古代印度
├─ 种姓制度（雅利安人）
│   ├─ 婆罗门（祭司）
│   ├─ 刹帝利（军事贵族）
│   ├─ 吠舍（平民）
│   └─ 首陀罗（被征服者）+ 贱民
│       特点：森严、世袭、不通婚
└─ 佛教（前 6 世纪，释迦牟尼）
    └─ 主张众生平等 → 前 3 世纪阿育王时期外传
```

## 课堂小结一句话

种姓把人分成四等，佛教说人本该平等——两者在同一片土地上同时存在。
