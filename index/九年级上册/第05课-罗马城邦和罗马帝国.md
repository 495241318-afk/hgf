册别: 九年级上册
单元: 第二单元 古代欧洲文明
课序: 5
课题: 罗马城邦和罗马帝国
课标要求: 知道罗马共和国的建立和扩张，了解罗马帝国的建立。
核心素养:
  - 时空观念
  - 历史解释
  - 唯物史观
关键词:
  - 罗马共和国
  - 元老院
  - 屋大维
  - 罗马帝国
  - 地中海
知识点:
  - 公元前 509 年建立共和国，权力掌握在元老院、执政官和公民大会手中，实质是贵族共和
  - 扩张：公元前 3 世纪统一意大利半岛，公元前 2 世纪称霸地中海
  - 公元前 27 年，屋大维建立元首制，罗马帝国开始
  - 2 世纪时帝国版图横跨欧、亚、非三洲，地中海成为罗马的“内湖”
  - 395 年帝国分裂为东西两部分；476 年西罗马帝国灭亡，标志西欧奴隶社会结束
重难点: 罗马从共和国到帝国的转变；罗马扩张的影响
易错点: 罗马共和国时期执政官由选举产生、任期一年，不是终身制；《十二铜表法》是罗马第一部成文法，不是第一部法典（《查士丁尼法典》才是法典编纂）；布匿战争的对手是迦太基，不是希腊；公元前 27 年屋大维建立元首制、罗马帝国建立，不是凯撒；395 年帝国分裂为东西两部分，476 年西罗马灭亡标志西欧奴隶社会结束
教学建议: 用一条时间轴把“共和—称霸—帝国—分裂—西罗马灭亡”串起来，每个节点只让学生记一个关键词，避免年份堆砌

## 板书提纲

```
罗马
├─ 前 509 共和国（元老院 + 执政官）——贵族共和
├─ 前 3 世纪 统一意大利 → 前 2 世纪 称霸地中海
├─ 前 27 屋大维 元首制 → 帝国
├─ 2 世纪 横跨三洲，地中海为“内湖”
└─ 395 分裂 → 476 西罗马灭亡（西欧奴隶社会结束）
```

## 课堂小结一句话

共和国的旗帜一直挂着，权力却一步步集中到了一个人手上。
