  - 唯物史观

  - 史料实证

  - 活字印刷
  - 指南针
  - 火药
  - 丝绸之路
  - 马可波罗
知识点:
  - 印刷术：北宋毕昇发明活字印刷术（泥活字），比欧洲早约四百年；元代王祯发明转轮排字法
  - 指南针：战国时已有司南，宋代制成罗盘并用于航海，后传入欧洲
  - 火药：唐朝已有记载，宋元时期广泛用于军事，后传入阿拉伯和欧洲
  - 中外交通：宋代海路发达，广州、泉州是重要港口；元代陆路畅通，驿站制度完善
  - 马可·波罗元朝来华，著《马可·波罗行纪》，激起欧洲人对东方的向往
  - 意义：四大发明外传推动了世界文明进程
重难点: 三大发明外传的世界影响
易错点: 活字印刷是北宋毕昇发明，不是东汉蔡伦（蔡伦改进造纸术）；指南针用于航海是宋代，不是战国；火药发明于唐朝，宋元广泛用于军事；马可·波罗是元朝来华，不是明朝
教学建议: 三大发明按“发明—改进—外传—影响”四步讲，形成统一分析框架；外传影响要具体：印刷术促进文化传播、指南针推动地理大发现、火药改变战争形态，学生才理解“改变世界”不是空话；可用培根的评价作为史料支撑

## 板书提纲

```
宋元时期的科技与中外交通
├─ 印刷术：北宋毕昇活字印刷（泥活字）
├─ 指南针：宋制罗盘用于航海
├─ 火药：唐有记载，宋元广用于军事
├─ 交通：宋海路（广州、泉州）；元陆路驿站
└─ 马可·波罗《行纪》→ 欧洲向往东方
   影响：推动世界文明进程
```

## 材料研读

“这三种东西曾改变了整个世界的面貌和状态……第一种在文学上，第二种在战争上，第三种在航海上。”——培根

设问：培根说的三种东西分别指什么？它们怎么改变世界的？
（要点：印刷术—知识传播；火药—战争与封建制度瓦解；指南针—远洋航行。）

## 课堂小结一句话

中国的几件小东西，从海路和陆路走出去，改写了别人的世界。
