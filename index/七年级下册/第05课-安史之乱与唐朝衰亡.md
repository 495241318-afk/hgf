课标要求: 知道安史之乱，了解唐朝衰亡和五代十国的局面。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 安史之乱
  - 藩镇割据
  - 黄巢起义
  - 五代十国
  - 由盛转衰
知识点:
  - 背景：唐玄宗后期怠于政事，任用奸臣，朝政腐败；节度使权力膨胀，中央与地方矛盾尖锐
  - 755 年，安禄山、史思明发动叛乱，763 年被平定，史称“安史之乱”
  - 影响：唐朝国势由盛转衰；北方经济遭到破坏，人口大量南迁；藩镇割据局面形成
  - 此后宦官专权、朋党之争，政治腐败
  - 875 年黄巢起义爆发，给唐朝统治以致命打击
  - 907 年，朱温建立后梁，唐朝灭亡，中国进入五代十国时期
重难点: 安史之乱是唐朝由盛转衰的转折点
易错点: 安史之乱是 755—763 年，安禄山、史思明发动；唐朝灭亡是 907 年朱温建后梁，不是安史之乱直接导致；安史之乱后形成藩镇割据，不是立刻灭亡；五代十国是唐朝灭亡后的分裂局面，不是唐朝内部的叛乱
教学建议: 用“盛世为什么突然崩了”设问，把玄宗前后期对比，学生看到“人还是那个人，政却不同了”；安史之乱的影响分三层：国势、经济、政治格局，逻辑清晰；结尾把唐亡—五代十国—宋统一串起来，形成长时段视野

```
│   ├─ 由盛转衰的转折点

```

## 材料研读

“渔阳鼙鼓动地来，惊破霓裳羽衣曲。”——白居易《长恨歌》

设问：一句诗里，“渔阳鼙鼓”和“霓裳羽衣曲”分别代表什么？
（要点：叛乱与盛世享乐；两句并置即盛衰转折的缩影。）

## 课堂小结一句话

一个节度使的野心，掀翻了一个盛世的桌子。
