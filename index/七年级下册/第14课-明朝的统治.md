课题: 明朝的统治
课标要求: 知道明朝的建立，了解明太祖强化君权的措施和科举的变化。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 朱元璋
  - 废丞相
  - 锦衣卫
  - 八股取士
  - 厂卫
知识点:
  - 1368 年朱元璋建立明朝，定都应天府（今南京）；后明成祖迁都北京
  - 政治：废除丞相制度和中书省，权分六部，直接对皇帝负责；设三司分掌地方权力
  - 特务：设锦衣卫，明成祖设东厂，合称“厂卫”，监视官民
  - 科举：实行八股取士，考试范围限于“四书”“五经”，答卷须按固定格式，不能自由发挥
  - 影响：君主专制空前加强；八股取士束缚思想，阻碍科技文化发展
重难点: 明朝君主专制强化的表现与影响
易错点: 朱元璋废除的是丞相制度（不是宰相这一称呼的取消），秦以来的丞相制到此终结；锦衣卫是明太祖设，东厂是明成祖设；八股取士考试范围是四书五经，答卷用八股文；明朝定都应天（南京），明成祖迁北京
教学建议: 用“皇帝为什么要亲自管六部”讲清废丞相的逻辑——不信任任何人；厂卫制度可用具体案例说明特务政治的恐怖；八股取士要让学生看一段八股范文的格式限制，直观感受“不能自由发挥”意味着什么

## 板书提纲

```
明朝的统治（1368—1644）
├─ 1368 朱元璋建明，都应天府；成祖迁北京
├─ 政治：废丞相、权分六部；地方设三司
├─ 特务：锦衣卫（太祖）、东厂（成祖）= 厂卫
├─ 科举：八股取士（四书五经，固定格式）
└─ 影响：君权空前加强；思想受束缚
```

## 材料研读

“以后子孙做皇帝时，并不许立丞相。”——明太祖《皇明祖训》

设问：把这条写进祖训，说明了什么？
（要点：对权臣的极度防范；以祖宗之法固化制度。）

## 课堂小结一句话

丞相没了，皇帝一个人要干几个人的活，于是特务替他盯着所有人。
