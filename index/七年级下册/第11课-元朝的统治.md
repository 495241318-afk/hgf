  - 唯物史观

  - 行省制度

  - 澎湖巡检司
  - 中书省

知识点:
  - 元朝疆域空前辽阔，“北逾阴山，西极流沙，东尽辽左，南越海表”
  - 中央设中书省掌行政、枢密院掌军事、御史台掌监察
  - 地方推行行省制度，行省下设路、府、州、县，加强对地方的控制
  - 设宣政院管理西藏地区，西藏正式成为中央政府直接管辖的地方行政区域
  - 设澎湖巡检司管辖澎湖和琉球（今台湾），这是中央政府首次在台湾地区正式设立行政机构
  - 设北庭都元帅府等管理西域
  - 意义：行省制度是中国省制的开端，加强了中央对边疆的管辖，促进统一多民族国家发展
重难点: 行省制的历史地位；元朝对边疆的管辖
易错点: 西藏正式归属中央管辖始于元朝（宣政院），不是唐朝（唐是和亲、会盟）；澎湖巡检司是元朝设的，管辖澎湖与琉球（台湾）；行省制度始于元朝，是中国省制开端；元朝中央不设门下省
教学建议: 行省制用“中央—行省—路府州县”层级图讲，说明它如何解决大疆域的管理难题；西藏、台湾、西域三处管辖务必落实到具体机构与今天的对应关系，这是维护国家统一的重要史实；结尾点出行省制影响至今，学生会有直观感受

## 板书提纲

```
元朝的统治
├─ 疆域：空前辽阔
├─ 中央：中书省（行政）、枢密院（军事）、御史台（监察）
├─ 地方：行省制度 → 路府州县（中国省制开端）
├─ 边疆
│   ├─ 宣政院管西藏（正式归属中央）
│   ├─ 澎湖巡检司管澎湖与琉球（台湾）
│   └─ 北庭都元帅府管西域
└─ 意义：加强边疆管辖，促统一多民族国家发展
```

## 材料研读

“北逾阴山，西极流沙，东尽辽左，南越海表。”——《元史·地理志》

设问：管理这样大的疆域，元朝在制度上做了什么创新？
（要点：行省制；中央派出机构变为地方最高行政机构。）

## 课堂小结一句话

元朝把疆域画得太大了，只好发明一种新办法来管它，这个办法一直用到现在。
