知识点:
  - 916 年，契丹族首领耶律阿保机建立契丹国（辽），都城上京
  - 1038 年，党项族首领元昊建立西夏，定都兴庆府
  - 960 年，赵匡胤建立北宋，定都开封
  - 辽与北宋多次战争，1005 年双方订立澶渊之盟：北宋给辽岁币，双方保持相对和平
  - 西夏与北宋也多次交战，后议和，西夏向北宋称臣，北宋给西夏岁币
  - 影响：虽给北宋带来财政负担，但保持了长期和平，促进边境贸易与民族交融
重难点: 澶渊之盟的评价
易错点: 契丹族建辽，党项族建西夏，女真族建金，三个民族与政权不能混；澶渊之盟是北宋给辽岁币，不是辽给宋；和约虽屈辱，但客观上维持了百余年和平，评价要两面；北宋与辽、西夏是并立关系，不是藩属关系
教学建议: 用“打不过就和”这条线讲清和约由来，避免简单贴“屈辱”标签；澶渊之盟评价要让学生自己权衡——岁币负担 vs 百年和平与榷场贸易，培养辩证思维；民族政权并立要用地图，学生才理解“多民族政权共存”是中国历史常态

## 板书提纲

```
辽、西夏与北宋的并立
├─ 916 契丹（耶律阿保机）建辽，都上京
├─ 1038 党项（元昊）建西夏，都兴庆府
├─ 960 赵匡胤建北宋，都开封
├─ 1005 澶渊之盟：宋给辽岁币 → 长期和平
├─ 宋夏议和：西夏称臣，宋给岁币
└─ 影响：财政负担 + 边境贸易、民族交融
```

## 材料研读

“澶渊之盟，宋岁输辽银十万两、绢二十万匹。”——《宋史》

设问：这笔岁币对北宋是纯损失吗？
（要点：财政负担确存；但换来百余年和平，榷场贸易收益部分抵消。）

## 课堂小结一句话

打不赢就谈，谈成了就做生意——这是十至十二世纪东亚的常态。
