课序: 4
课题: 洋务运动
课标要求: 了解洋务运动的主要内容，初步认识洋务运动的作用和局限性。
核心素养:
  - 唯物史观
  - 史料实证
  - 历史解释
  - 家国情怀
关键词:
  - 洋务派
  - 自强求富
  - 江南机器制造总局
  - 轮船招商局
  - 京师同文馆
知识点:
  - 时间：19 世纪 60 年代到 90 年代中期
  - 目的：利用西方先进技术，强兵富国，维护清王朝统治
  - 代表：中央以奕䜣为代表，地方以曾国藩、李鸿章、左宗棠、张之洞为代表
  - 口号：前期“自强”，后期“求富”
  - 军事工业：安庆内军械所、江南机器制造总局、福州船政局
  - 民用企业：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局
  - 教育：创办京师同文馆等新式学堂，派遣留学生出国深造
  - 军事：组建北洋、南洋、福建三支海军
  - 结局：甲午中日战争中国战败，标志洋务运动破产
  - 评价：中国历史上第一次近代化运动；客观上促进了中国民族资本主义的产生；但只学技术不改制度，未能使中国富强
重难点: 洋务运动的性质与历史作用；为什么“只学技术”走不通
易错点: 洋务运动是地主阶级的自救运动，不是资产阶级改革（戊戌变法才是）；京师同文馆是洋务运动中创办的，不是戊戌变法时的京师大学堂；北洋舰队全军覆没于甲午战争，标志洋务运动破产，不是鸦片战争；洋务派办企业是为了维护清朝统治，不是发展资本主义
教学建议: 先摆出“两次鸦片战争都输了”这个背景，问学生“清朝官员想到的办法是什么”，自然引出“师夷长技”；军事工业与民用企业的关系要讲清，前者“自强”、后者“求富”，求富是为自强服务的；最后用甲午战败做闭环，让学生自己得出结论：不改变制度，光买船买炮救不了国

## 板书提纲

```

├─ 背景：两次鸦片战争失败，内忧外患
├─ 目的：强兵富国，维护清朝统治
├─ 代表：奕䜣、曾国藩、李鸿章、左宗棠、张之洞
├─ 内容
│   ├─ 军事工业（自强）：安庆内军械所、江南机器制造总局、福州船政局
│   ├─ 民用企业（求富）：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局
│   ├─ 教育：京师同文馆、派遣留学生

```

## 材料研读

“中国文武制度，事事远出西人之上，独火器万不能及……中国欲自强，则莫如学习外国利器。”——李鸿章《筹议海防折》

设问：李鸿章这段话里，哪半句是洋务运动的动力，哪半句是它失败的根源？
（要点：承认器物落后是动力；坚信“文武制度远出西人之上”正是致命误判。）

## 思维训练：一条走不通的路

| 层次 | 洋务派做了什么 | 结果 |
| --- | --- | --- |
| 器物 | 买船买炮、办厂办学 | 甲午一战，舰队覆没 |
| 制度 | 未触动 | 封建专制照旧 |
| 思想 | 未触及 | “中体西用”自我设限 |

设问：如果只换工具不换制度，能救得了这个国家吗？让学生带着这个问题进入下一课。

## 课堂小结一句话

洋务派造出了中国第一批机器，却造不出一个能支撑机器的制度。
