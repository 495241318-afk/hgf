册别: 七年级上册
单元: 第一单元 史前时期：中国境内早期人类与文明的起源
课序: 3
课题: 远古的传说
课标要求: 了解炎帝、黄帝的传说故事，知道尧舜禹的禅让。
核心素养:
  - 唯物史观
  - 史料实证
  - 家国情怀
关键词:
  - 炎黄
  - 涿鹿之战
  - 禅让
  - 大禹治水
  - 人文初祖
知识点:
  - 炎帝、黄帝是传说中黄河流域部落联盟的首领，黄帝被尊为“人文初祖”
  - 炎黄部落联盟在涿鹿之战中打败蚩尤，后逐渐形成华夏族
  - 传说中炎帝教民耕种、发明医药，黄帝建造宫室、制作衣裳、发明舟车
  - 禅让制：尧年老时把位置让给舜，舜让给禹，推举贤德之人继位
  - 大禹治水，采用疏导方法，三过家门而不入
  - 传说与史实的区别：传说有夸张成分，但往往包含真实的历史信息，需要考古印证
重难点: 传说与史实的区别；禅让制的实质
易错点: 涿鹿之战是炎黄部落联合打败蚩尤，不是炎帝打败黄帝；黄帝是“人文初祖”，不是炎帝；禅让制是推举贤德者，不是父死子继（那是世袭制）；禹是最后一位通过禅让继位的首领，其子启开创世袭制
教学建议: 先问“传说算不算历史”，让学生辨析，再讲考古发现如何印证传说（如陶寺遗址），培养史料意识；禅让与世袭的对比可以放在本课结尾，为下一课“夏传子、家天下”埋线；大禹治水讲方法（疏导）而不只讲精神，学生更能理解治水成功的逻辑

## 板书提纲

```
远古的传说
├─ 炎黄部落（黄河流域）
│   ├─ 涿鹿之战：炎黄联合败蚩尤
│   └─ 华夏族形成；黄帝=人文初祖
├─ 禅让制：尧 → 舜 → 禹（推举贤德）
└─ 大禹治水：疏导之法，三过家门而不入
```

## 材料研读

“劳身焦思，居外十三年，过家门不敢入。”——《史记·夏本纪》

设问：这段记载属于传说还是信史？我们能从中得到什么可靠信息？
（要点：出自后世追述，含有加工；但反映了治水之艰难与领袖的公共责任。）

## 课堂小结一句话

传说不等于历史，但一个民族反复讲述的故事里，藏着它最初的样子。
