课标要求: 知道春秋时期诸侯争霸的史实，理解这一时期的社会变化。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 春秋五霸
  - 齐桓公
  - 尊王攘夷
  - 铁制农具
  - 井田制
知识点:
  - 公元前 770 年，周平王东迁洛邑，史称东周，分为春秋和战国两个时期
  - 经济变化：铁制农具和牛耕出现并推广，生产力提高；私田增多，井田制逐步瓦解
  - 政治变化：周王室衰微，诸侯不再听从周王命令，分封制遭到破坏
  - 争霸：齐桓公任用管仲改革，以“尊王攘夷”为口号，成为春秋时期第一个霸主
  - 著名霸主：齐桓公、晋文公、楚庄王、秦穆公等（说法不一，教材以主要几位为例）
  - 影响：给社会带来灾难，但客观上促进了局部统一和民族交融
重难点: 铁器牛耕对社会变革的推动作用
易错点: 东周开始的标志是公元前 770 年周平王东迁，不是三家分晋；齐桓公是春秋第一个霸主，靠“尊王攘夷”，不是靠武力直接灭周；铁制农具出现在春秋时期，不是战国；井田制瓦解的根本原因是生产力发展（铁器牛耕），不是诸侯争霸
教学建议: 用“一件农具如何改变一个时代”做主线，铁器牛耕提高效率 → 私田开垦 → 井田制瓦解 → 诸侯实力变化 → 争霸，这条链要让学生自己推出来；霸主评价要两面说，战争有破坏也有整合；本课是理解战国变法的前提，务必把“生产力变化引发制度变化”这个逻辑立住

## 板书提纲

```
动荡的春秋时期（前770—前476）
├─ 前770 平王东迁洛邑 → 东周开始
├─ 经济：铁农具 + 牛耕 → 私田增 → 井田制瓦解
├─ 政治：王室衰微，分封制破坏
├─ 争霸：齐桓公（管仲改革，尊王攘夷）首霸
│        晋文公、楚庄王等
└─ 影响：灾难 + 客观促统一与交融
```
