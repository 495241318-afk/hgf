  - 秦始皇
  - 郡县制
  - 中央集权
  - 统一文字
  - 统一货币
知识点:
  - 秦灭六国：公元前 230—前 221 年，嬴政先后灭韩赵魏楚燕齐，建立秦朝，定都咸阳
  - 皇帝制度：嬴政自称“始皇帝”，总揽全国军政大权
  - 中央官制：丞相、太尉、御史大夫，合称三公，分管行政、军事、监察
  - 地方制度：废分封、行郡县，郡下设县，郡县长官由朝廷直接任免
  - 巩固统一的措施：统一文字为小篆、统一货币为圆形方孔半两钱、统一度量衡、统一车轨修驰道、开凿灵渠、北击匈奴修长城
  - 疆域：东至东海，西到陇西，北至长城一带，南达南海
重难点: 郡县制与分封制的本质区别；专制主义中央集权制度对中国历史的长远影响
易错点: 县制春秋战国已出现，但全面推行郡县制始于秦朝，不要说“秦朝首创县”；“焚书坑儒”属秦朝暴政，与本题的巩固统一措施要分开答；灵渠沟通的是湘江与漓江，不是黄河与长江
教学建议: 一张结构图讲透制度——皇帝→三公→郡→县，让学生标出“谁任免谁”；用秦半两钱与六国货币实物图做“统一货币”情境体验，问学生“商人最想要什么”

## 板书提纲

```
秦统一中国（前221）
├─ 统一：灭六国 → 咸阳
├─ 制度
│   ├─ 皇帝制度（最高权力）
│   ├─ 三公（丞相/太尉/御史大夫）
│   └─ 郡县制（中央任免，非世袭）
└─ 巩固
    ├─ 文化：小篆
    ├─ 经济：半两钱、度量衡
    └─ 交通军事：驰道、灵渠、长城
```

## 对比突破：分封制 vs 郡县制

| 比较项 | 分封制 | 郡县制 |
| --- | --- | --- |
| 官员来源 | 周王分封，血缘为主 | 皇帝任免，不论血缘 |
| 是否世袭 | 世袭 | 不世袭，可调动 |
| 与中央关系 | 相对独立，易割据 | 直接听命中央 |

设问：如果你是秦始皇，刚刚灭掉六国，你最担心什么？据此说明为什么要推行郡县制。

## 课堂小结一句话

秦朝统一的不只是疆土，更是文字、货币和权力的尺度。
