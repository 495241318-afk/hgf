课序: 11
课题: 西汉建立和“文景之治”
课标要求: 知道西汉的建立，了解“文景之治”的史实。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
关键词:
  - 刘邦
  - 休养生息
  - 文景之治
  - 轻徭薄赋
  - 黄老无为
知识点:
  - 公元前 202 年，刘邦建立汉朝，定都长安，史称西汉
  - 汉初经济凋敝，“民失作业，而大饥馑”，刘邦采取休养生息政策
  - 措施：让士兵复员生产、释放奴婢、减轻田租（十五税一）、鼓励生育
  - 汉文帝、汉景帝继续推行：注重农业，轻徭薄赋（三十税一），提倡勤俭治国，重视“以德化民”
  - 结果：政治清明，经济发展，人民生活安定，国力增强，史称“文景之治”
  - 为汉武帝时期的大一统奠定物质基础
重难点: 休养生息政策与“文景之治”的关系
易错点: 西汉建立是公元前 202 年，定都长安，不是洛阳（东汉都洛阳）；刘邦实行的是“休养生息”，核心是黄老无为、与民休息；“文景之治”是文帝、景帝两朝，不包括刘邦；三十税一是文帝时期，十五税一是汉初
教学建议: 先把“汉初有多穷”讲透（天子找不到四匹同色马），学生才能理解为什么必须无为而治；把秦的“多取”与汉初的“少取”对照，一条政策对比就能说明治乱之别；结尾点明这是“恢复期”，为武帝的有为铺垫，形成“无为—有为”的节奏

## 板书提纲

```
西汉建立和“文景之治”
├─ 前202 刘邦建汉，都长安
├─ 背景：经济凋敝，民生困苦
├─ 高祖：休养生息（复员、释奴、十五税一）
├─ 文帝、景帝
│   ├─ 重农、轻徭薄赋（三十税一）
│   ├─ 勤俭治国、以德化民
│   └─ 结果：文景之治
└─ 意义：为武帝大一统奠定物质基础
```

## 材料研读
