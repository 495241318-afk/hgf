课题: 百家争鸣
课标要求: 知道老子和孔子，了解百家争鸣的主要学派及其主张。
核心素养:
  - 唯物史观
  - 史料实证
  - 历史解释
  - 家国情怀
关键词:
  - 老子
  - 孔子
  - 儒家
  - 道家
  - 百家争鸣
知识点:
  - 老子：春秋后期楚国人，道家学派创始人，主张“无为而治”，认为事物有对立面并可相互转化，著《道德经》
  - 孔子：春秋后期鲁国人，儒家学派创始人，核心思想是“仁”，主张“为政以德”；创办私学，主张“有教无类”；其言论被弟子整理成《论语》
  - 战国时期百家争鸣：墨家墨子主张“兼爱”“非攻”；儒家孟子主张“仁政”、民贵君轻；荀子主张礼治；道家庄子强调顺应自然；法家韩非主张以法治国、树立君主权威、建立中央集权专制统治
  - 背景：铁器牛耕推广，社会大变革，各学派纷纷著书立说，互相辩论
  - 影响：促进了思想文化的繁荣，是中国古代第一次思想文化发展的高峰，对后世影响深远
重难点: 孔子与儒家思想；各学派主张与时代需求的关系
易错点: 老子是道家创始人，孔子是儒家创始人，不能混；孔子核心是“仁”，主张德治；韩非是法家，主张法治与中央集权，与儒家对立；百家争鸣出现在战国时期，孔子、老子是春秋时期人；《论语》是弟子整理的，不是孔子亲笔
教学建议: 先讲“为什么这个时代会冒出这么多思想家”，把社会大变革作为土壤，学生才理解思想是现实的回应；各派主张可用“治国方案竞标”的方式呈现——儒家讲德、法家讲法、道家讲无为、墨家讲兼爱，让学生判断“哪一家最可能被国君采用”，答案是法家，顺势带出秦的统一；孔子部分要落到教育贡献，有教无类在当时是革命性的

## 板书提纲

```
百家争鸣
├─ 老子（春秋，道家）：无为而治，对立转化
├─ 孔子（春秋，儒家）
│   ├─ 核心：仁；为政以德
│   └─ 教育：有教无类，创办私学
├─ 战国诸子
│   ├─ 墨家 墨子：兼爱、非攻
│   ├─ 儒家 孟子：仁政、民贵君轻；荀子：礼治
│   ├─ 道家 庄子：顺应自然
│   └─ 法家 韩非：法治、中央集权
└─ 影响：第一次思想文化高峰
```

## 材料研读

“己所不欲，勿施于人。”——《论语》

“世异则事异，事异则备变。”——韩非

设问：两句话对“怎么治理人”给出了什么不同答案？
（要点：前者以道德自律与推己及人；后者以制度与法度因时变革。）

## 课堂小结一句话

一个乱世，逼出了中国思想史上最热闹的一场辩论。
