课题: 太平天国运动
课标要求: 了解太平天国运动的兴衰，认识其意义和局限性。
核心素养:
  - 唯物史观
  - 时空观念
  - 历史解释
  - 家国情怀
关键词:
  - 洪秀全
  - 金田起义
  - 天京
  - 天朝田亩制度
  - 资政新篇
知识点:
  - 背景：鸦片战争后赔款负担转嫁农民，阶级矛盾激化，自然灾害频发
  - 组织：洪秀全在广西创立拜上帝会，以宗教形式发动群众
  - 兴衰线：1851 年金田起义 → 永安建制 → 1853 年攻占南京、改名天京、定都 → 北伐西征 → 1856 年天京事变由盛转衰 → 1864 年天京陷落
  - 《天朝田亩制度》：不分男女，按人口和年龄平均分配土地；反映农民要求得到土地的强烈愿望，但绝对平均主义无法实现
  - 《资政新篇》：洪仁玕提出，主张向西方学习、发展资本主义，是先进中国人最早提出的在中国发展资本主义的方案，但未实施
  - 性质：中国历史上规模最宏大的一次农民战争
  - 意义：沉重打击了清朝统治和外国侵略势力
重难点: 《天朝田亩制度》的革命性与空想性；太平天国由盛转衰的转折点
易错点: 定都天京是 1853 年（攻占南京之后），不是金田起义当年；天京事变是领导集团内讧，不是被清军打败；《资政新篇》是洪仁玕写的，不是洪秀全；《天朝田亩制度》要平均分配土地，但从未真正施行
教学建议: 用“农民为什么能掀起这么大一场运动”切入，把鸦片战争后的赔款摊派、白银外流讲透，学生才明白太平天国的土壤；两条纲领文件一定要对比讲——一个向后看（平均主义）、一个向前看（资本主义），这个对比是本课思维含量最高处；结尾落到“农民阶级的局限性”，为后面讲无产阶级领导埋下伏笔

## 板书提纲

```
太平天国运动（1851—1864）
├─ 背景：赔款转嫁 + 灾荒 → 阶级矛盾激化
├─ 洪秀全：拜上帝会 → 1851 金田起义
├─ 1853 定都天京（南京）
│   ├─《天朝田亩制度》→ 平均土地，空想
│   └─《资政新篇》→ 学习西方，未实施
├─ 1856 天京事变 → 由盛转衰
└─ 1864 天京陷落
   性质：规模最大的农民战争
   意义：打击清朝统治与外国侵略势力
```

## 材料研读

“凡分田，照人口，不论男妇，算其家人口多寡，人多则分多，人寡则分寡……凡天下田，天下人同耕。”——《天朝田亩制度》

“倘能依法而行，则太平一统，共享天福。”——《资政新篇》

设问：两份文件都想要一个更好的社会，为什么一份行不通、一份根本没机会行？
（要点：《天朝田亩制度》建立在小农平均主义之上，违背经济规律；《资政新篇》超前于时代，缺乏阶级基础与安定环境。）

## 两条纲领对比

| 项目 | 《天朝田亩制度》 | 《资政新篇》 |
| --- | --- | --- |
| 提出者 | 太平天国 | 洪仁玕 |
| 方向 | 回到小农平均 | 走向资本主义 |
| 是否施行 | 未真正推行 | 未实施 |
| 局限 | 绝对平均，空想 | 超前，无社会基础 |
