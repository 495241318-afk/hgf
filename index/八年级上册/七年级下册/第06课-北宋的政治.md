  - 赵匡胤
  - 陈桥兵变
  - 杯酒释兵权
  - 重文轻武
  - 通判
知识点:
  - 北宋建立：960 年，赵匡胤（宋太祖）发动陈桥兵变，建立宋朝，定都东京（开封）
  - 收兵权：杯酒释兵权，解除禁军将领兵权，禁军由皇帝直接控制
  - 收行政权：文臣知州，设通判监督知州，分化事权
  - 收财权：设转运使，把地方财赋收归中央
  - 重文轻武：文官掌军、扩大科举取士规模、武举地位下降、武将受牵制
  - 影响：加强了中央集权，有利于政权稳定和社会安定；但造成军队战斗力弱、财政负担沉重
重难点: 北宋加强中央集权措施的作用与弊端
易错点: 北宋并未完成全国统一，长期与辽、西夏、金并立；“重文轻武”不等于不重视军事，而是文人掌军、武将受制；转运使管财政、通判监督知州，职责不能互换
教学建议: 用“皇帝最怕什么”驱动全课——怕武将夺权、怕地方坐大、怕财赋旁落，让学生把三条措施与三种担忧一一对应；用表格归纳“措施—针对的问题—带来的后果”，落在“利与弊”的双面评价上

## 板书提纲

```
北宋的政治（960）
├─ 建立：陈桥兵变 → 东京
├─ 集权三招
│   ├─ 兵：杯酒释兵权、禁军归皇帝
│   ├─ 权：文臣知州 + 通判监督
│   └─ 钱：转运使收财赋
└─ 重文轻武 → 稳定 ↑ 战力 ↓ 财政 ↑
```

## 课堂讨论

宋太祖说：“朕今用儒臣干事者百余人，分治大藩，纵皆贪浊，亦未及武臣一人也。”

设问：这句话暴露了宋太祖最怕什么？这种思路给北宋埋下了什么隐患？
（要点：怕武臣拥兵自重；隐患是财政冗费、军事积弱，为后来与辽夏金的被动局面埋下伏笔。）

## 课堂小结一句话

北宋用文官换来了内部的安稳，也用文官换走了对外的锋芒。
