课序: 16
课题: 明朝的科技、建筑与文学
课标要求: 知道《本草纲目》《天工开物》《农政全书》，了解明长城、北京城和明清小说。
核心素养:
  - 唯物史观
  - 史料实证
  - 家国情怀
关键词:
  - 本草纲目
  - 天工开物
  - 农政全书
  - 明长城
  - 明清小说
知识点:
  - 医药：李时珍《本草纲目》，记载药物 1800 多种，被誉为“东方医药巨典”
  - 科技：宋应星《天工开物》，总结农业和手工业生产技术，被誉为“中国 17 世纪的工艺百科全书”
  - 农学：徐光启《农政全书》，全面总结农业生产经验
  - 建筑：明长城东起鸭绿江、西至嘉峪关；北京城以紫禁城为核心，布局严整
  - 文学：明清小说繁荣，《三国演义》《水浒传》《西游记》《红楼梦》为四大名著
重难点: 三部科技著作的价值；长城的功能与象征
易错点: 《本草纲目》是李时珍（医药），《天工开物》是宋应星（工艺），《农政全书》是徐光启（农业），三者不能混；明长城东起鸭绿江，不是山海关；《红楼梦》是清代作品，不是明代；四大名著中《红楼梦》成书最晚
教学建议: 三本书按“医、工、农”三个字记住作者与内容，比死记全名有效；长城讲功能（防御）与代价（劳役），避免单一赞颂；小说部分可讲《三国演义》为何受市民欢迎，呼应前面市民文化的线索

## 板书提纲

```
明朝的科技、建筑与文学
├─ 科技
│   ├─ 李时珍《本草纲目》（医药）
│   ├─ 宋应星《天工开物》（工艺百科）
│   └─ 徐光启《农政全书》（农业）
├─ 建筑：明长城（东起鸭绿江，西至嘉峪关）
│        北京城、紫禁城
└─ 文学：四大名著（《红楼梦》为清代）
```

## 材料研读

“贵五谷而贱金玉。”——宋应星《天工开物》序

设问：这句话反映了作者怎样的价值观？与他的写作对象有何关系？
（要点：重视实用生产；面向农业与手工业的实际技术。）

## 课堂小结一句话

三本书，一本管看病，一本管做工，一本管种地——这是明朝的底气。
