课题: 鸦片战争
课标要求: 讲述林则徐虎门销烟的故事，认识鸦片战争对中国近代社会的影响。
核心素养:
  - 唯物史观
  - 史料实证
  - 时空观念
  - 家国情怀
关键词:
  - 虎门销烟
  - 林则徐
  - 南京条约
  - 半殖民地半封建
  - 协定关税
知识点:
  - 背景：英国完成工业革命，急需打开中国市场；正常贸易中中国处于出超地位，英国转而走私鸦片
  - 鸦片危害：白银大量外流、财政危机、吏治腐败、军队战斗力削弱、损害国人身心健康
  - 虎门销烟：1839 年 6 月 3 日至 25 日，林则徐在广东虎门海滩当众销毁鸦片 110 多万公斤
  - 战争经过：1840 年 6 月英国舰队侵入，攻广州、定海，北犯天津大沽；1842 年 8 月清政府战败求和
  - 《南京条约》内容：割香港岛给英国；赔款 2100 万银元；开放广州、厦门、福州、宁波、上海五处为通商口岸；英商进出口货物应纳税款须与英国协商（协定关税）
  - 影响：中国开始沦为半殖民地半封建社会，是中国近代史的开端
重难点: 鸦片战争爆发的根本原因；《南京条约》对中国社会性质的影响
易错点: 根本原因是英国要打开中国市场，虎门销烟只是借口和导火线，不能说“虎门销烟导致战争”；割让的是香港岛，不是整个香港；五口通商不含天津；"半殖民地半封建"要能分别解释（主权部分丧失、自然经济开始解体）
教学建议: 用中英正当贸易白银流向图切入，先讲“英国为什么必须卖鸦片”，再讲“禁烟为什么必然引发战争”，把因果链讲实；《南京条约》四条逐条推演“丢了什么主权”，最后落到社会性质的变化；本课可作为“近代史开端”的锚点课，后面各课反复回扣

## 板书提纲

```
鸦片战争（1840—1842）
├─ 根本原因：英国要打开中国市场
├─ 导火线：虎门销烟（1839.6.3—25，林则徐）
├─ 结果：战败，《南京条约》（1842）
│   ├─ 割香港岛 → 领土主权
│   ├─ 赔 2100 万银元 → 财政
│   ├─ 五口通商 → 贸易主权
│   └─ 协定关税 → 关税主权
└─ 影响：开始沦为半殖民地半封建社会（近代史开端）
```

## 材料研读

“鸦片流毒于天下，则为害甚巨，法当从严。若犹泄泄视之，是使数十年后，中原几无可以御敌之兵，且无可以充饷之银。”——林则徐《钱票无甚关碍宜重禁吃烟以杜弊源片》

设问：林则徐是从哪两个角度论证必须禁烟的？这反映了他怎样的立场？
（要点：军队与国家财政，即统治根基；站在维护清朝统治的立场，同时也体现了民族责任感。）

## 因果链训练

英国要求打开市场 → 正常贸易入超 → 走私鸦片 → 白银外流、军队衰弱 → 清政府禁烟 → 英国借机发动战争 → 战败签约 → 社会性质改变

让学生把这条链打乱后重排，检验是否真正理解“根本原因”与“导火线”的区别。

## 课堂小结一句话

虎门海滩那把火烧掉的是鸦片，烧出来的是一个时代的转折。
