册别: 八年级上册
单元: 第二单元 近代化的早期探索与民族危机的加剧
课序: 5
课题: 甲午中日战争与列强瓜分中国狂潮
课标要求: 知道甲午中日战争的主要战役；列举《马关条约》的主要内容，说明《马关条约》与中国民族危机加剧的关系。
核心素养:
  - 时空观念
  - 史料实证
  - 家国情怀
关键词:
  - 黄海海战
  - 邓世昌
  - 马关条约
  - 资本输出
  - 瓜分狂潮
知识点:
  - 背景：日本明治维新后走上对外扩张道路，蓄谋侵略中国
  - 主要战役：1894 年丰岛海战爆发；平壤战役；黄海海战（邓世昌与致远舰）；日军旅顺大屠杀；威海卫战役，北洋舰队全军覆没
  - 《马关条约》：1895 年李鸿章与伊藤博文签订，割辽东半岛、台湾全岛及所有附属各岛屿、澎湖列岛给日本；赔款白银 2 亿两；开放沙市、重庆、苏州、杭州为商埠；允许日本在通商口岸开设工厂
  - 三国干涉还辽：俄、德、法出面干涉，中国付出 3000 万两白银“赎辽费”
  - 瓜分狂潮：列强强租租借地、划分“势力范围”；1899 年美国提出“门户开放”政策
重难点: 《马关条约》的内容及其对中国民族危机的影响
易错点: 赔款是白银 2 亿两，《南京条约》才是 2100 万银元，两个数字极易混；“允许开设工厂”标志列强侵华由商品输出为主转向资本输出为主，这是本科最关键的一句；北洋舰队全军覆没于威海卫战役，不是黄海海战；割让范围包括台湾全岛及所有附属岛屿、澎湖列岛
教学建议: 与《南京条约》做四栏对比表（割地、赔款、通商、特权），让学生自己得出结论“程度大大加深”，比教师直接讲结论有效；用“2 亿两相当于清政府数年财政收入”做数字冲击，再问“这笔钱最后由谁承担”

## 板书提纲

```
甲午中日战争（1894—1895）
├─ 战役：丰岛→平壤→黄海（邓世昌）→旅顺→威海卫（北洋覆没）
├─ 结果：《马关条约》
│   ├─ 割：辽东、台湾及附属岛屿、澎湖
│   ├─ 赔：2 亿两
│   ├─ 开：沙市、重庆、苏州、杭州
│   └─ 设厂：资本输出（关键转折）
└─ 后续：三国干涉还辽 → 瓜分狂潮 → 门户开放
```

## 对比表：两个不平等条约

| 比较项 | 《南京条约》1842 | 《马关条约》1895 |
| --- | --- | --- |
| 割地 | 香港岛 | 辽东半岛、台湾及附属岛屿、澎湖列岛 |
| 赔款 | 2100 万银元 | 2 亿两白银 |
| 通商 | 广州、厦门、福州、宁波、上海 | 沙市、重庆、苏州、杭州 |
| 特权 | 协定关税 | 允许在通商口岸开设工厂 |

设问：从这张表里，你能看出列强对中国的侵略发生了什么变化？
（要点：从沿海深入内地；从商品输出转向资本输出；从掠夺市场转向分割领土。）

## 课堂小结一句话

《南京条约》让中国开始失去主权，《马关条约》让中国几乎失去领土。
