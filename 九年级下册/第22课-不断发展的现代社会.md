课标要求: 了解现代社会的科技发展、人口、环境等问题。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证

关键词:
  - 互联网
  - 人口增长
  - 环境问题
  - 妇女地位
  - 可持续发展
知识点:
  - 科技：20 世纪四五十年代以来，计算机与互联网迅速发展，人类进入信息时代；生物技术、新材料、新能源等取得突破
  - 互联网的影响：改变生产生活方式，促进信息交流；也带来网络安全、隐私等问题
  - 人口：世界人口快速增长，带来粮食、就业、资源压力
  - 环境：全球气候变暖、臭氧层破坏、酸雨、水污染、土地荒漠化等问题突出
  - 社会：妇女地位提高，但性别平等仍待推进
  - 应对：走可持续发展道路，加强国际合作；中国提出人与自然和谐共生、构建人类命运共同体
重难点: 科技与社会的双重影响；可持续发展的必要性
易错点: 信息时代以计算机与互联网为标志；环境问题具有全球性，需要国际合作解决；妇女地位提高但仍存在不平等，不能一概而论；可持续发展强调经济、社会、环境协调，不是只讲环保
教学建议: 用“一部手机如何改变一天”讲信息时代，贴近学生生活；环境问题用具体数据（气温、冰川），避免空喊；结尾落到“发展与代价”的辩证关系和可持续理念，本课可作为整套教材的收束课

## 板书提纲

```
不断发展的现代社会
├─ 科技：计算机 + 互联网 → 信息时代
│   └─ 影响：便利与安全隐私问题并存
├─ 人口：快速增长 → 粮食、就业、资源压力
├─ 环境：气候变暖、臭氧破坏、污染、荒漠化
├─ 社会：妇女地位提高，仍待平等
└─ 应对：可持续发展 + 国际合作
```
