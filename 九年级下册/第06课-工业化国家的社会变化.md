课题: 工业化国家的社会变化
课标要求: 了解工业化带来的人口增长、城市化和社会问题。
核心素养:
  - 唯物史观
  - 时空观念
  - 史料实证
  - 历史解释
关键词:
  - 人口增长
  - 城市化
  - 环境污染
  - 贫富分化
  - 教育普及
知识点:
  - 人口增长：工业革命后生产力提高、医疗改善，欧美人口迅速增长
  - 劳动力结构变化：农业人口比重下降，工业和服务业人口上升；妇女走出家庭进入工厂
  - 教育普及：1802 年英国通过第一部《工厂法》，此后各国推行义务教育，大众教育推广
  - 城市化：大量人口涌入城市，城市规模扩大，19 世纪中期英国城市人口超过总人口一半
  - 社会问题：贫富分化加剧；城市卫生、住房、犯罪问题突出；环境污染严重
  - 认识：工业化是双刃剑，既带来进步，也带来新的社会矛盾
重难点: 工业化的双重影响
易错点: 城市化伴随工业化出现，不是先有城市再有工业；妇女大量进入工厂是工业化的结果，但同工不同酬长期存在；社会问题（贫富分化、污染）是工业化的伴生物，不能因此否定工业化的历史进步性
教学建议: 用“同一个城市的两张面孔”讲——一边是工厂与铁路，一边是贫民窟与烟囱；数据对比（人均寿命、童工比例）比描述更有力；结尾要引导学生辩证看待，既承认进步，也正视代价，这为后面讲环境问题与社会改革埋线

## 板书提纲

```
工业化国家的社会变化
├─ 人口增长（生产力 + 医疗）
├─ 劳动力结构：农业↓ 工业服务业↑；妇女进厂
├─ 教育普及：工厂法、义务教育
├─ 城市化：英国城市人口过半（19 世纪中期）
└─ 社会问题：贫富分化、卫生住房、犯罪、污染
   认识：工业化是双刃剑
```

## 材料研读

“这是最好的时代，这是最坏的时代。”——狄更斯《双城记》

设问：这句话为什么常被用来形容工业革命？
（要点：财富与贫困、进步与苦难同时并存。）
