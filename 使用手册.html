二、备课查一课：30 秒

  1. 打开检索页，在搜索框输入关键词（如“洋务运动”“推恩令”“冷战”）。
  2. 点册别按钮缩小范围；点卡片展开，看到课标、核心素养、知识点、重难点、易错点、教学建议。
  3. 要投屏就按 Ctrl+P 直接打印，或把某个知识点的文字复制到课件里。

三、改一课：1 分钟，不用装软件

  1. 打开仓库，进 index/ → 点册别文件夹 → 点开那一课（文件名形如 第04课-洋务运动.md）。
  2. 点右上角的铅笔图标进入编辑，直接改正文或元数据。
  3. 页面下方点 Commit changes。约 1—2 分钟后网页自动更新，不用手动发布。

写坏了也不要紧：提交后系统会自动校验。字段缺失、课序重复会被直接拦下并提示错在哪一行，网页不会变成乱版。

四、加一课：复制模板，改五个地方

  1. 打开 templates/课时模板.md，右上角点“复制原始文件”把内容复制下来。
  2. 进 index/对应册别/，点 Add file → Create new file，文件名写 第07课-课题名.md（课序两位数）。
  3. 粘贴内容，至少改这五项：册别、单元、课序、课题、状态。
  4. 下方提交。校验通过后，检索页和覆盖度报表会自动多出这一课。

五、出一份练习：一条命令，六册都能出

在仓库文件夹里打开终端（Windows 用 Git Bash 或 PowerShell），运行以下命令。第一次用先装依赖：pip install -r requirements.txt；Windows 上命令里的 python 若报错，换成 py，Mac 上换成 python3。

想要什么命令
整册（辨析 + 填空）python scripts/quiz.py -b 八年级上册
只要一个单元python scripts/quiz.py -b 八年级上册 -u 第三单元
加上简答题python scripts/quiz.py -b 九年级下册 -t 辨析,填空,简答

不想装 Python：仓库里点 Actions → 生成题库 → Run workflow，填册别运行，两分钟后题库自动提交回仓库，手机上打开 题库/打印版.html 就能看题。

产物都在 题库/ 目录：八年级上册.md 是题库，含答案与出处，便于校对；八年级上册-打印版.html 用浏览器打开后按 Ctrl+P 直接印，答案在最后一页。

题型说明：辨析题把易错点原位改成两个选项（如“洋务运动是（A. 资产阶级改革 / B. 地主阶级的自救运动）”），题干取自原文，不会出现机器造句的病句；填空题挖年代、文献、关键名词；简答题按重难点设问。自动出题只作初稿，印前扫一眼答案里的出处，按班级情况微调。

六、维护节奏：别让它变成负担

时间做什么耗时
每上完一个单元把“教学建议”补一句真实课堂反馈（学生最卡在哪），状态改为 已定稿5 分钟
每学期末看覆盖度报表，补定稿率低的册；顺手清掉过时的教学建议10 分钟
教材或课标修订用检索页搜“课标”，把变动过的课时统一更新按需

七、四条底线

① 不放教材原件。只放自己整理的要点，不传 PDF 与扫描页（版权），仓库已屏蔽 *.pdf。

② 不写学生信息。仓库是公开的，不要出现姓名、成绩、班级排名。

③ 打不开先换网。github.io 在国内偶发不通，换手机流量或等几分钟即可；长期影响可加国内镜像。

④ 共享给同事。直接发链接，对方无需注册即可查看；要一起改，把他加成协作者。

八、这个库为什么值得维护

它不是网盘，是可检索、可校验、有留痕的资料库：每次改动都有记录，字段写错会被自动拦下，六册 129 课结构一致，换册换年级都不用重新适应。带新人时，一份链接就是一套现成的备课底稿。
